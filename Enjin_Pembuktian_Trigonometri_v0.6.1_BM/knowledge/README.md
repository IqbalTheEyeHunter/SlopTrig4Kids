# Panduan fail pengetahuan

## Fail yang dipaparkan kepada pengguna

- `Panduan_Identiti_MS.md` — pustaka rujukan identiti trigonometri dalam Bahasa Melayu. Mengandungi 136 entri berindeks. Formula, syarat matematik dan ID identiti dikekalkan supaya rujukan sepadan dengan enjin.

## Fail kanonik untuk enjin

- `SKILL.md` — spesifikasi katalog kanonik yang dibaca oleh enjin untuk memuatkan peraturan identiti dan menyemak kebergantungan. Fail ini dikekalkan dalam bahasa asal supaya parser dan padanan peraturan tidak berubah.

**Penting:** Terjemahan paparan tidak mengubah nama fungsi, rumus, ID identiti, skema sijil atau kod status dalaman. Hal ini memastikan edisi Bahasa Melayu kekal serasi dengan enjin pembuktian v0.6.1.
