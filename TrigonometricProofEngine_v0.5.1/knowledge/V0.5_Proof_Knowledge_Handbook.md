# v0.5 — Foundations, scope and proof safety

**Status:** mathematical knowledge and implementation specification, not an executable theorem prover. All new proof recipes require a checker before software may label their instances PROVED. Version 0.5 here identifies this knowledge package, not a released desktop binary.

## 1. What this collection covers

This is a systematic finite collection of proof methods for real trigonometric identities, conditional identities, equations and inequalities. Infinitely many problems can be generated; no finite list is literally exhaustive. The practical objective is coverage of the principal reusable methods, their prerequisites, and their failure modes.

The default input language remains the six real functions sin, cos, tan, cot, sec and csc. Coordinates, lengths, areas, vectors, matrices and polynomials are auxiliary proof objects. Optional analytic modules introduce derivatives, integrals, series and complex numbers inside proofs. Those modules are explicit extensions, not silently available assumptions. Inverse functions are optional output notation for equation solutions; the core can describe a reference angle by an interval and its sine/cosine instead.

All unmarked angles use radians. Degree input must be converted exactly before applying a radian formula. Variables denoting lengths, radii, natural numbers or integer period indices carry types and constraints.

## 2. Distinguish the problem being solved

| Kind | Required conclusion | Insufficient conclusion |
|---|---|---|
| Identity | L=R for every assignment in the stated original domain | Equality at sampled angles |
| Conditional identity | Assumptions imply L=R, with assumptions retained | Proof after silently adding assumptions |
| Equation | Exact solution set, with necessity and sufficiency | Some verified roots without completeness |
| Inequality | Bound on its full domain, plus equality cases when requested | A numerical plot |
| Simplification | Equivalent expression on the original domain | Enlarging the domain after cancellation |
| Geometric theorem | Conclusion for every configuration meeting construction hypotheses | A convincing drawing |

For equations, use SOLVED_COMPLETE, SOLUTIONS_VERIFIED_INCOMPLETE, NO_SOLUTIONS_PROVED or INCONCLUSIVE. For identities use PROVED, DISPROVED, INCONCLUSIVE, INVALID_INPUT or UNDEFINED_ON_REQUESTED_DOMAIN. Proposed new statuses need UI support; they are not claims about the v0.4.1 interface.

## 3. Choose a foundation profile

### GEO: Euclidean geometry and signed unit-circle coordinates

Trusted background: ordered real arithmetic; Euclidean incidence, congruence, parallels, similarity, ordinary area; oriented angle measure and rotation existence; correspondence between an oriented ray and a unit-circle point. Prove the nontrigonometric Pythagorean theorem from dissection or similarity. Define cosine and sine as the signed coordinates of the unit-circle point. Define the other four functions by quotients/reciprocals.

The equation X²+Y²=1 is DERIVED from the Euclidean distance of a unit-circle point, before substituting X=cos x and Y=sin x. Do not enter sin²x+cos²x=1 as a root assumption when that is the target.

### SERIES: real power-series definitions

Define S(x)=Σ(-1)^n x^(2n+1)/(2n+1)! and C(x)=Σ(-1)^n x^(2n)/(2n)!. Establish convergence, permitted differentiation and S'=C, C'=-S. Derive identities using analysis. Identification with geometrically defined sine/cosine requires an explicit bridge theorem matching orientation, parameter scale and initial values.

### ODE: independent differential-equation definitions

Define S and C as the unique global solution of S'=C, C'=-S, S(0)=0, C(0)=1. Existence and uniqueness are declared analysis prerequisites. Derive norm preservation and addition by differential equations. This is independent of F08 only if the ODE facts were not themselves obtained from F08-dependent geometry.

### COMPLEX: independently defined exponential

Define exp by its convergent complex series or an independently established differential equation. Prove multiplication, conjugation and nonvanishing. Derive real sine/cosine from exp(ix). Never claim this is an independent proof of F08 if Euler's formula was previously obtained by assuming F08.

**Profile discipline:** Every certificate names its profile, trusted background and bridge certificates. A theorem cannot switch definitions midway merely because the symbols have the same spelling. Analytic profiles are optional; GEO suffices for the core geometry update.

## 5. Proof objects rather than a blacklist of names

A theorem statement and a derivation are different objects. F08 may have a dissection-based proof, a similar-triangle proof, or an analytic proof. Each has its own proof ID and dependency list. Selecting one proof must not automatically import dependencies of every alternative.

Example permitted route:

AX.AREA + AX.EUCLID + AX.REAL → G01 dissection → G03 distance relation → G04 unit-circle F08 proof.

Example rejected route:

F08 goal → F09 → F08 admitted as a premise.

Example legitimate use after proving F08 independently:

F08 goal → F09 lemma → independently checked geometric certificate for F08.

The last route is redundant and should be shortened to the geometric proof, but a repeated theorem label does not itself create a logical cycle if the selected proof objects form a finite rooted derivation and no unresolved goal is assumed. The checker should examine proof-object ancestry and open assumptions, not only theorem names. Conversely, renaming an assumed F08 to “Lemma Z” does not remove circularity.

### Required admission rules

1. Parse the goal without normalizing away trigonometric identities. Keep the original expression tree and domain.
2. Separate definitions, explicit assumptions, background facts, checked theorem certificates and mere catalogue statements.
3. A catalogue statement or a prose proof is not executable authority by itself.
4. Expand each selected proof's dependencies recursively to allowed foundations. Unknown provenance means reject that route.
5. Track the active proof stack. A repeated active proof node is a cycle. Shared completed subproofs are legal.
6. Any local assumption equivalent to the goal cannot discharge the goal. Check reversals, renamed variables, algebraic rearrangements and instantiated schemas.
7. Alpha-renaming and algebraic normalization may aid matching; if equivalence is uncertain, do not silently accept the premise. Matching true identities by `trigsimp(lhs-rhs)==0` would collapse unrelated theorems into one statement and is invalid.
8. The conclusion of a legitimate geometric derivation may equal the goal. That is success, not circularity. Do not ban proof construction merely because its conclusion is F08.
9. A theorem whose only available proof uses F08 is unavailable while F08 is an open assumption, unless its dependency can be discharged by an independently checked F08 subproof.
10. Check typed inference rules, substitutions, domain implications and final goal equality. SymPy truth checks and floating-point agreement cannot substitute for this.

## 6. Domain and assumption ledger

Maintain original domain D0, branch assumptions B, constructed-object conditions C, and intermediate denominator conditions Di separately. To conclude an identity on D0, prove that D0 implies each needed condition, or cover D0 by branches. Reporting only D0∩Di is a restricted result, not the original claim.

- Division: record nonzero divisor or split zero/nonzero cases.
- Multiplication: valid for equality, but its reverse needs nonzero multiplier or separate cases.
- Squaring: an implication unless sign restrictions justify equivalence.
- Square roots: √(u²)=|u|. Removing absolute values needs a sign proof.
- Triangle ratios: require a nondegenerate right triangle; they initially prove results only for acute angles.
- Circle geometry: signed coordinates cover all quadrants; lengths remain nonnegative.
- Tangent lines/intersections: prove existence and nonparallel/nonzero denominators.
- Continuity: may fill a gap only where both ORIGINAL expressions are defined and continuous. It cannot define an original 0/0 expression.
- Contradictory assumptions: mark the branch empty; do not market a vacuous result as an unconditional identity.
- Empty original domain: report it explicitly; do not display a meaningful universal identity badge.

## 7. Required certificate shape

A serialized certificate needs: schema/version; profile; claim kind; exact original AST; variable types; original domain; assumptions; construction objects; proof nodes; dependencies; local substitutions; rule IDs; discharged conditions; remaining conditions; final conclusion; trusted foundations; checker version; result status. Equation certificates additionally require candidate-generation implications, case partitions, parameter ranges, rejected candidates, sufficiency proofs and completeness proofs.

Each proof node uses one rule: definition expansion, construction introduction, geometric theorem instantiation, exact polynomial identity, guarded rational identity, equality substitution, inequality inference, case split/merge, induction, or an explicitly enabled analytic rule. A human explanation accompanies the node but does not validate it.

Store content hashes and proof IDs to avoid certificate substitution; a hash confirms identity of bytes, not mathematical truth. JSON validity, a dependency DAG and a successful unit test are not substitutes for rule checking.

F01–F20, S01–S18, A01–A21, D01–D16, H01–H21, P01–P12, R01–R18 and I01–I10 remain stable. B and W identifiers remain legacy explanation/example references. W19, W85 and W88 are deliberately false claims, never theorem premises.

# v0.5 — Geometric proof bank

All recipes below are mathematical derivations. A diagram illustrates a construction; it is not evidence of equality. Lengths are nonnegative; coordinate components and oriented angles may be negative. Dependencies refer to the foundation registry or earlier recipes. A recipe covering a family of identities must be instantiated with exact variables and hypotheses.

## G01 — Pythagorean theorem by dissection, without trigonometry

**Claim:** In a right triangle with positive legs a,b and hypotenuse c, a²+b²=c².

**Dependencies:** AX.REAL, AX.EUCLID, AX.AREA.

Construct a square of side a+b. Put one congruent copy of the right triangle at each corner, with its legs along the square's sides, so the four hypotenuses bound the central quadrilateral. Each central side has length c. At each central vertex the two adjacent acute triangle angles sum to a right angle, so the central angle is π/2. Thus the central quadrilateral is a square, not just a rhombus.

Add areas: (a+b)² = 4(ab/2)+c². Expanding and subtracting 2ab gives a²+b²=c². No sine, cosine, F08 or cosine rule was used. Degenerate zero-leg cases follow directly by equality of the remaining segment lengths, not by asserting similarity of a degenerate triangle.

**Machine obligations:** congruence of the four copies, disjoint interiors, complete partition, four central right angles, positive lengths, area expansion.

## G02 — Independent Pythagorean proof by similar triangles

**Dependencies:** AX.REAL, AX.EUCLID, AX.SIMILARITY.

Let ABC be right-angled at C; AB=c, AC=b, BC=a. Drop CD perpendicular to AB, with AD=m and DB=n. The two smaller triangles are similar to ABC by AA. Corresponding side ratios yield b²=cm and a²=cn. Add them and use m+n=c: a²+b²=c(m+n)=c². The foot lies inside the hypotenuse for a nondegenerate right triangle.

This is a genuinely different proof object for the same geometric theorem. Do not cite G01 if presenting G02 as independent of it.

## G03 — Cartesian squared distance from geometry

**Dependencies:** G01 (or G02 as a separate alternative), Cartesian axes from AX.EUCLID, AX.REAL.

For P=(u,v), the perpendicular projections create legs |u| and |v|. Pythagoras gives OP²=|u|²+|v|²=u²+v². If either coordinate is zero, segment length on an axis gives the same result. Translating the construction gives PQ²=(u₂-u₁)²+(v₂-v₁)². This derives the coordinate formula rather than assuming F08 to establish it.

## G04 — F08 from the unit circle, all real angles

**Dependencies:** D.UNIT, G03.

1. Choose arbitrary real x, including negative angles and multiple turns.
2. Construct the unit-circle point P on the ray of oriented angle x. By construction OP=1.
3. Write P=(u,v). The definitions say u=cos x and v=sin x.
4. G03 gives u²+v²=OP²=1.
5. Substitute the coordinate definitions to obtain cos²x+sin²x=1.
6. Reorder the sum if the requested claim is sin²x+cos²x=1.

There is no denominator and no quadrant restriction. Axis points are covered by G03. F08 is the conclusion, not a premise. The certificate should show G01/G02 and G03, or clearly expose these as independently justified geometric background facts.

**Expected v0.5 report:** PROVED by Euclidean geometry, once the geometric checker is implemented. In v0.4.1 this remains INCONCLUSIVE.

## G05 — F08 from right-triangle ratios, with an explicit extension

**Dependencies:** AX.SIMILARITY, G01, D.UNIT, AX.ORIENT.

For 0<x<π/2, a right triangle of hypotenuse r has opposite leg r sin x and adjacent leg r cos x by similarity with the unit-radius construction. Pythagoras divided by r²>0 gives F08. This alone proves only the acute case.

For a non-axis angle in any quadrant, reflect its ray to an acute reference angle α. Its coordinate magnitudes are cos α and sin α in the appropriate order; squaring removes the reflection signs. At axis angles the coordinates are (±1,0) or (0,±1), so the sum of squares is one. Full turns preserve the point. Record these cases to obtain all real x.

## G06 — Quotient and reciprocal functions as geometric ratios

**Dependencies:** D.UNIT, D.QUOT, AX.SIMILARITY, AX.ORIENT.

For an acute right triangle, tan x=opposite/adjacent, cot x=adjacent/opposite, sec x=hypotenuse/adjacent and csc x=hypotenuse/opposite. Divide the similar-triangle coordinate ratios to verify consistency with D.QUOT. For arbitrary angles, use signed coordinate ratios, not unsigned side lengths. Domains: cos x≠0 for tan/sec; sin x≠0 for cot/csc.

F01–F04 are definitions in this profile. The ratio discussion interprets the definitions; it does not pretend to prove a definition from itself.

## G07 — Tangent and secant as a tangent-line construction

**Dependencies:** G03, G06, D.UNIT, AX.CIRCLE.

The unit-circle tangent at E=(1,0) is the vertical line X=1. The complete line through O in direction (cos x,sin x) intersects it when cos x≠0. The intersection is T=(1,sin x/cos x)=(1,tan x). Its squared distance from O is OT²=1+tan²x. Since T=(1/cos x)(cos x,sin x), its length is |sec x|. Therefore 1+tan²x=sec²x.

When cos x<0, T lies on the opposite ray, not the original forward ray. This is why OT=|sec x|, not sec x. A rigorous vector scaling argument or similar-triangle argument must justify the length relation.

This proves F09 geometrically, but with the specified coordinate/distance construction it is not automatically an independent route for F08. Keep the actual dependencies, including any normalization theorem used for the direction vector.

## G08 — Cotangent and cosecant construction

**Dependencies:** G03, G06, D.UNIT, AX.CIRCLE.

Intersect the complete direction line with Y=1, requiring sin x≠0. The point is (cot x,1), with distance |csc x| from O. Pythagoras gives 1+cot²x=csc²x. Apply the same sign and dependency cautions as G07.

## G09 — Reflection, half-turn and full-turn identities

**Dependencies:** D.UNIT, AX.ORIENT, AX.EUCLID.

Reflection in the horizontal axis sends (u,v) to (u,-v) and angle x to -x, proving cos(-x)=cos x and sin(-x)=-sin x. Reflection in the vertical axis sends it to (-u,v), proving cos(π-x)=-cos x and sin(π-x)=sin x. A half-turn sends it to (-u,-v); a full turn returns the same point. Thus sine/cosine have the stated half-turn signs and period 2π. Quotient/reciprocal definitions give the corresponding rules for tan, cot, sec and csc on their domains. The tangent/cotangent period π follows because both numerator and denominator change sign.

These facts do not require F08 as an algebraic premise. “Period 2π” here means 2π is a period; establishing the least positive period is a separate uniqueness/ray argument.

## G10 — Quarter-turns and cofunctions

**Dependencies:** D.UNIT, AX.ORIENT, AX.EUCLID.

A counterclockwise quarter-turn maps (u,v) to (-v,u), by perpendicularity, equal lengths and orientation of Cartesian axes. Reflection in the line Y=X maps (u,v) to (v,u). These constructions establish sin(π/2+x)=cos x, cos(π/2+x)=-sin x, sin(π/2-x)=cos x and cos(π/2-x)=sin x. Apply D.QUOT to obtain cotangent/tangent and cosecant/secant cofunctions. Do not derive the quarter-turn coordinate map from an unproved general rotation formula.

## G11 — General rotation formula from basis images

**Dependencies:** D.UNIT, G10, AX.LINEAR, AX.ORIENT.

Let R_y be the geometric rotation through y. The image of e₁=(1,0) is (cos y,sin y). Since e₂ is a quarter-turn of e₁, G10 gives R_y(e₂)=(-sin y,cos y). Linearity now gives

R_y(u,v)=uR_y(e₁)+vR_y(e₂)=(u cos y-v sin y, u sin y+v cos y).

Linearity of Euclidean rotations must come from geometric/vector background, not from already assuming this matrix. The formula holds for signed u,v and every real y.

## G12 — Sine/cosine addition and subtraction

**Dependencies:** G11, G09, D.UNIT, AX.ORIENT.

Rotate P=(cos x,sin x) through y. Geometrically the resulting angle is x+y, so its coordinates are (cos(x+y),sin(x+y)). G11 calculates the same coordinates as

(cos x cos y-sin x sin y, sin x cos y+cos x sin y).

Equate components to obtain A03 and A01. Replace y by -y and apply G09 for A04 and A02. The construction proves all real angles directly; no acute-only extension or intermediate division is needed.

## G13 — Dot product, projections and cosine difference

**Dependencies:** G11, G03, AX.LINEAR.

For nonzero vectors u,v with oriented arguments α,β, rotate both by -β; Euclidean rotation preserves the coordinate dot product, as follows from its independently proved isometry/orthonormal-basis properties. The rotated v is (|v|,0), so u·v=|u||v|cos(α-β). For unit vectors, expansion gives cos(α-β)=cos α cos β+sin α sin β.

This is a useful alternative presentation. It is not an independent proof of addition if dot-product invariance was established using that same addition identity. The manifest uses the basis-rotation route, making this dependence explicit.

## G14 — Determinant, oriented area and sine difference

**Dependencies:** G11, AX.AREA, AX.LINEAR.

For vectors u,v, det(u,v)=u₁v₂-u₂v₁ is the signed parallelogram area. Rotating u to the positive horizontal axis leaves oriented area unchanged, giving det(u,v)=|u||v|sin(β-α). For unit vectors this becomes sin(β-α)=cos α sin β-sin α cos β. Triangle area is half the absolute determinant. A clockwise ordering changes the determinant's sign, not the ordinary area.

## G15 — Cosine rule by a perpendicular projection

**Dependencies:** G03, G04, G06, AX.EUCLID.

In a nondegenerate triangle let AB=c>0, AC=b>0 and ∠BAC=A∈(0,π). Place A=(0,0), B=(c,0), C=(b cos A,b sin A). With BC=a, G03 gives a²=(b cos A-c)²+(b sin A)²=b²+c²-2bc cos A by G04.

The coordinate construction covers obtuse A because b cos A may be negative. It does not assume the perpendicular foot lies on segment AB. Since this proof uses G04, it cannot be cited as an independent proof of F08.

## G16 — Triangle area formula and sine rule

**Dependencies:** G06, AX.AREA; optionally G10 for the obtuse-height interpretation.

For positive sides b,c enclosing A∈(0,π), altitude to the line of side c has height b sin A>0, including the obtuse case. Hence Δ=bc sin A/2. Cyclically Δ=ca sin B/2=ab sin C/2. Divide by abc/2>0 to obtain sin A/a=sin B/b=sin C/c, and invert since the sines of interior nondegenerate triangle angles are positive.

This proves equality of a/sin A, b/sin B and c/sin C. The value 2R requires the next circle theorem; it is not assumed here.

## G17 — Inscribed angles, chord length and the extended sine rule

**Dependencies:** AX.CIRCLE, AX.EUCLID, G06, G09, G10.

First prove the inscribed-angle theorem: join the vertex and chord endpoints to the centre; the radii form isosceles triangles. Add or subtract their base-angle relations according to the centre's position. The central angle subtending the same arc is twice the inscribed angle, with the correct choice of arc. This is elementary angle geometry, not a use of the sine rule.

For a circle of radius R>0, bisect the minor central angle θ∈[0,π] subtending a chord. The perpendicular bisector gives two right triangles, each with opposite length R sin(θ/2). Thus chord length=2R sin(θ/2). For a triangle inscribed in the circle, the minor central angle opposite A is 2A if A≤π/2, and 2π-2A otherwise. Reflection gives sin(π-A)=sin A. Thus a=2R sin A, and similarly for b,c. Endpoint/diameter cases are checked directly.

## G18 — Cyclic quadrilaterals and Ptolemy

**Dependencies:** G17, G12, G04, G09, AX.REAL.

For distinct A,B,C,D in cyclic order, write the successive positive arc measures as 2α,2β,2γ,2δ, where α+β+γ+δ=π. Chord formulas give AB=2R sin α, BC=2R sin β, CD=2R sin γ, AD=2R sin δ, AC=2R sin(α+β), BD=2R sin(β+γ). These sines are nonnegative; a major arc gives the same chord through the supplementary half-angle.

Expand by G12:

sin(α+β)sin(β+γ)-sin β sin(α+β+γ)
=sin α sin γ(cos²β+sin²β)=sin α sin γ.

Since sin δ=sin(α+β+γ), multiply by 4R² to obtain AC·BD=AB·CD+BC·AD.

This is a complete trigonometric proof of Ptolemy, useful for later geometry. It depends on addition and F08, so it cannot be recycled as an independent foundation for either. A synthetic similarity proof would need a separate checked construction and proof object. Arbitrary four points do not satisfy this equality without the cyclic/order conditions.

## G19 — Tangent–chord and power-of-a-point methods

**Dependencies:** AX.CIRCLE, AX.EUCLID, AX.SIMILARITY, G17's inscribed-angle theorem.

A radius is perpendicular to its tangent. Comparing this right angle with the centre/inscribed-angle relations proves the tangent–chord angle theorem for the appropriate segment. Similar triangles then give the external tangent–secant relation PT²=PA·PB (P outside, A the nearer intersection, B the farther) and the two-secant relation PA·PB=PC·PD. Intersecting chords inside a circle give PA·PB=PC·PD with ordinary positive segment lengths. A single signed formula covering internal/external cases needs directed lengths.

Use these relations to express constructed lengths in two ways, then replace ratios by sine/cosine where legal. They are not free-standing trig rewrite rules, and their geometric incidence hypotheses must be part of the certificate.

## G20 — Exact values from special triangles

**Dependencies:** G01, G06, AX.EUCLID, AX.SIMILARITY, G09, G10.

An isosceles right triangle with legs 1 has hypotenuse √2, hence sin(π/4)=cos(π/4)=1/√2. An equilateral triangle of side 2 split by an altitude has hypotenuse 2, shorter leg 1 and longer leg √3; this gives sin(π/6)=1/2, cos(π/6)=√3/2 and the π/3 values by cofunctions. Axis coordinates supply 0 and π/2. Reflections and turns supply other quadrants. Quotient/reciprocal definitions give the remaining four functions wherever defined. Addition/subtraction then gives π/12 and 5π/12.

A regular pentagon route supplies 18°/36° values only after independently establishing its diagonal ratio. The final radicals alone are not a proof of that ratio.

## G21 — Double and half angles from rotations and chords

**Dependencies:** G12, G04, AX.REAL.

Set y=x in G12: sin 2x=2sin x cos x and cos 2x=cos²x-sin²x. Use G04 for the forms 1-2sin²x and 2cos²x-1. Replace x by x/2 and rearrange to obtain sin²(x/2)=(1-cos x)/2 and cos²(x/2)=(1+cos x)/2.

Taking principal square roots gives |sin(x/2)| and |cos(x/2)|. A quadrant assumption is necessary to choose a sign. Chord bisection offers a geometric visualization but does not remove this sign requirement for arbitrary real angles.

## G22 — Stereographic rational parameterization of the circle

**Dependencies:** G03, G04, G17, G10, D.QUOT, AX.REAL.

Let P=(c,s) lie on the unit circle, P≠(-1,0). The line through (-1,0) and P has slope t=s/(1+c), so s=t(1+c). Substitute into c²+s²=1:

(c+1)[(1+t²)c+t²-1]=0.

Exclude c=-1 in this chart. Since 1+t²>0, c=(1-t²)/(1+t²), s=2t/(1+t²). The inscribed-angle/half-angle construction or G21 gives t=tan(x/2) when P=(cos x,sin x). Record x≠(2k+1)π. In equation solving check P=(-1,0), i.e. every omitted odd-π angle, separately.

This method is algebraically powerful but depends on the circle relation. It cannot independently prove F08 merely by substituting these parameterizations.

## G23 — Phase and amplitude from a rotated coefficient vector

**Dependencies:** G04, G12, D.UNIT, AX.REAL.

For a,b real, set R=√(a²+b²). If R=0, the combination a sin x+b cos x is identically zero. Otherwise (a/R,b/R) is a unit vector, so choose an oriented phase φ with cos φ=a/R, sin φ=b/R. G12 gives a sin x+b cos x=R sin(x+φ).

This proves existence of φ geometrically without requiring inverse functions in the input language. To calculate φ numerically, quadrant-aware angle selection is necessary; atan(b/a) alone loses quadrants and fails when a=0.

## G24 — Geometric bounds and equality cases

**Dependencies:** G04, G23, AX.REAL; or the nonnegative-square proof below.

Coordinates of a unit-circle point satisfy |sin x|≤1 and |cos x|≤1. For s=sin x,c=cos x, expand

(a²+b²)(s²+c²)-(as+bc)²=(ac-bs)²≥0.

Using G04 yields |a sin x+b cos x|≤√(a²+b²). Equality requires ac-bs=0; for nonzero (a,b), the unit vector (s,c) must be parallel or antiparallel to (a,b). This is the two-dimensional Cauchy–Schwarz inequality with an explicit equality condition. It proves the exact amplitude bound and gives a no-solution test for equations exceeding it.

## G25 — Geometric equation solving by intersections

**Dependencies:** G04, G09, G10, D.UNIT, AX.REAL.

sin x=k corresponds to the horizontal line Y=k intersecting X²+Y²=1. For |k|>1 there are no intersections; for k=±1 one tangent point; for |k|<1 two points per full turn. cos x=k uses X=k. tan x=m uses Y=mX with X≠0: two antipodal circle points, hence period π for angles.

For a sin x+b cos x=c, intersect bX+aY=c with the circle. If R=√(a²+b²)>0, the perpendicular distance of the line from the origin is |c|/R; compare this to 1. When R=0, the equation is either true for all real x (c=0) or has no solution (c≠0). This establishes branch counts; explicit general solution families appear in the equation module.

## G26 — Triangle-angle conditional identities

**Dependencies:** G12, G09, G21, D.QUOT, AX.REAL.

For A+B+C=π, sine addition gives sin(A+B)=sin C. Expand sin(A+B+C)=0 and divide by cos A cos B cos C only when it is nonzero to get tan A+tan B+tan C=tan A tan B tan C. Divide the same four-term expansion by sin A sin B sin C to get cot A cot B+cot B cot C+cot C cot A=1 on that domain.

For a geometric triangle also require A,B,C>0; for these algebraic conditional identities the equality A+B+C=π and the relevant domains suffice. Do not impose triangle positivity when it is unnecessary, or omit it for a theorem about actual triangle side lengths.

## G27 — Similarity and area-ratio workflow

**Dependencies:** AX.SIMILARITY, AX.AREA, G06.

Useful template: construct an altitude or angle bisector; prove triangles similar by named angle equalities; establish positive side ratios; express one ratio trigonometrically; eliminate the constructed length by another ratio. For area ratios with a common altitude, areas are proportional to bases. For a common included angle, the areas ½ab sin θ and ½cd sin θ have ratio ab/(cd), provided the sine and relevant lengths do not vanish. This is a workflow, not a universally applicable theorem.

Applications include projection identities, triangle cevian problems, and sine-rule derivations. Reject a proposed similarity if it follows only from how the diagram looks.

## G28 — Reflection and equal-chord equation methods

**Dependencies:** G09, G10, G17, D.UNIT.

Equal sine means equal vertical coordinate: on the unit circle the points coincide or reflect in the vertical axis. Thus sin u=sin v iff u=v+2kπ or u=π-v+2kπ. Equal cosine means coincidence or horizontal-axis reflection, giving u=±v+2kπ. Equal tangents means the direction lines coincide, hence u=v+kπ, with both tangents defined. A proof of completeness uses the circle-line intersection classification, not just substitution of the listed answers.

## G29 — When geometric proofs do not generalize

A right-triangle drawing proves an acute-angle statement until an extension is supplied. An inscribed-angle picture may cover only one ordering of points; alternate arcs change signs or supplements. A measured chord verifies one angle, not all angles. A construction that places a point at the intersection of parallel lines is invalid. A diagram with a zero-area triangle cannot justify dividing by its height.

Geometric proving requires configuration predicates: collinear, perpendicular, parallel, between, oriented-angle equality, circle membership, cyclic order, positivity, and nondegeneracy. These predicates must be checked or declared hypotheses. Generated images may illustrate a proof but must never be parsed as mathematical certificates.

## G30 — Approved foundation route for the reported F08 failure

Use G01 → G03 → G04, with D.UNIT and the explicit Euclidean/area background. Do not route through F09, F10, cosine rule, rational parameterization, or a rotation-norm calculation that was previously verified with F08. If a geometric rule checker is unavailable, show the human derivation and mark it DOCUMENTED_PROOF; do not upgrade the desktop engine's status to PROVED based only on this Markdown.

# v0.5 — Algebraic, vector and discrete methods

These methods complement geometry. Each trig fact used inside them must already have an independent certificate. Exact algebra can be a checker primitive; general symbolic trigonometric simplification cannot.

## M01 — Equality chains and a common form

Transform L through justified equalities to R, or transform both to the same C. Every intermediate expression must be defined on the branch. Starting with L=R and deriving a true statement is not enough unless every step is reversible, or necessity and sufficiency are separately established.

Example: sec x-cos x=(1-cos²x)/cos x=sin²x/cos x=sin x tan x. Dependencies: D.QUOT and G04; domain cos x≠0. This cannot independently establish G04.

## M02 — Quotient/reciprocal normalization

Replace tan by sin/cos, cot by cos/sin, sec by 1/cos and csc by 1/sin, recording denominators before cancellation. Use a common denominator and a polynomial numerator. E.g. tan x+cot x=(s²+c²)/(sc)=1/(sc), where s=sin x, c=cos x and sc≠0. Introduce s,c as abbreviations with definitions, not as arbitrary independent variables when invoking s²+c²=1.

## M03 — Factoring, conjugates and guarded cancellation

Use polynomial identities such as a²-b²=(a-b)(a+b), a³+b³=(a+b)³-3ab(a+b), and binomial expansion. Guard rational cancellation by a nonzero condition.

Example: (1-cos x)/sin x = sin x/(1+cos x) on sin x≠0. From G04, sin x≠0 implies cos x≠±1, so the introduced conjugate denominator is nonzero. This implication must be recorded; multiplication by (1+cos x)/(1+cos x) is not automatic.

If solving an equation containing a factor f, split f=0 and f≠0 before dividing by it. An identity calculation with a denominator in its ORIGINAL expression has different obligations from an equation that merely contains f as a factor.

## M04 — Polynomial reduction modulo the circle relation

After certified angle expansion and denominator clearing, replace sin x by s and cos x by c. Let h=s²+c²-1, certified by G04. A polynomial target P=0 follows if exact polynomial algebra supplies Q with P=Qh. A general certificate may use P=ΣQ_i h_i for several certified relations.

Example: P=s⁴+c⁴-1+2s²c²=(s²+c²-1)(s²+c²+1). The checker multiplies the factors exactly and uses h=0. This proves sin⁴x+cos⁴x=1-2sin²x cos²x.

A zero Gröbner remainder can guide discovery, but preserve the explicit multipliers or a verifiable reduction trace. A nonzero remainder means only that this reduction did not establish the claim. It is not automatically a counterexample. Algebraic identities may hold on a real constrained subset without belonging to the chosen polynomial ideal.

## M05 — Multiple angles and multiple variables

For independent angles x,y, use (s_x,c_x) and (s_y,c_y), with a circle relation for each. For x+y, use certified addition constraints rather than treating s_(x+y) as independent. Rationally related angles can be handled through a shared base angle and integer recurrences. For unrelated real frequencies, do not force a common integer-frequency polynomial model without justification.

Conditional assumptions, e.g. x+y+z=π, require a certified angle substitution or extra constraints. A polynomial relation is not a proof that every algebraic point corresponds to a valid angle configuration; completeness claims for equation solving need that converse.

## M06 — Rational identities and denominator certificates

Write L-R=N/D on the ORIGINAL domain, verify D≠0 there, and prove N=0. Do not assert that N=0 and the original equation have identical solution sets when D can vanish. For systems using polynomial elimination, retain inequalities D_i≠0; saturation or an auxiliary relation u·∏D_i-1=0 can encode nonzero denominators algebraically. Projection back to real angles remains a separate obligation.

Example: sin x/sin x=1 is valid only for x≠kπ. Canceling the fraction does not remove those holes.

## M07 — Product-to-sum and sum-to-product

Add/subtract the independently proved sine/cosine addition formulas:

- 2sin u cos v=sin(u+v)+sin(u-v).
- 2cos u sin v=sin(u+v)-sin(u-v).
- 2cos u cos v=cos(u+v)+cos(u-v).
- 2sin u sin v=cos(u-v)-cos(u+v).

Substitute u=(x+y)/2 and v=(x-y)/2 for sum-to-product. All these identities have full real domain. They are useful for factorizing equations, comparing frequencies, telescoping sums and deriving conditional triangle identities. Reversing an already certified equality is legal; using a target formula as its own unproved expansion is not.

## M08 — Multiple-angle recurrence and induction

From addition/subtraction,

sin((n+1)x)=2cos x sin(nx)-sin((n-1)x),
cos((n+1)x)=2cos x cos(nx)-cos((n-1)x).

With T₀(t)=1, T₁(t)=t and U₀(t)=1, U₁(t)=2t, both polynomial families obey p_(n+1)=2tp_n-p_(n-1). Induction proves cos(nx)=T_n(cos x) for n≥0 and sin(nx)=sin x U_(n-1)(cos x) for n≥1. Do not divide the latter by sin x unless it is nonzero.

Record two base cases for a second-order recurrence and the integer restriction on n. Numerical checks at n=1,2,3 are not induction.

## M09 — Triple-angle identities without intermediate domain loss

Use sin(2x+x) and cos(2x+x), substitute double angles and G04, to obtain sin 3x=3s-4s³ and cos 3x=4c³-3c. Their quotient gives tan 3x=(3t-t³)/(1-3t²) when cos x cos 3x≠0, using t=s/c.

Avoid a derivation through tan 2x on the entire desired domain: cos 2x may vanish even when cos x and cos 3x do not. Either split that case or use the sine/cosine polynomial derivation. This illustrates why a valid final formula can have a flawed intermediate proof.

## M10 — Power reduction and symmetric polynomials

Use sin²x=(1-cos 2x)/2 and cos²x=(1+cos 2x)/2, derived from G21. Repeatedly square and reduce to obtain even powers; distribute with exact coefficients. Alternatively set a=s²,b=c² with a+b=1. Then a³+b³=1-3ab, giving sin⁶x+cos⁶x=1-3sin²x cos²x. For general a^n+b^n use the recurrence p_n=(a+b)p_(n-1)-ab p_(n-2), with p₀=2,p₁=a+b.

Neither a+b=1 nor the power-reduction formulas are independent premises for proving F08.

## M11 — Tangent half-angle rationalization

Use G22 to transform rational expressions in sine/cosine into rational functions of t. Then exact polynomial/rational algebra may establish equality for finite t. The missing point x=(2k+1)π must be checked if the original expressions are defined there. For identities, a continuity argument may sometimes cover it, but only with continuity proved at those original points. For equations, explicitly solve the omitted branch.

This is a coordinate chart, not a bijection from all real angles to all real t. On any appropriate open interval of length 2π it covers the circle minus one point; periodicity supplies all turns.

## M12 — Finite telescoping sums

From addition,

2sin(d/2)cos(a+kd)=sin(a+(k+1/2)d)-sin(a+(k-1/2)d).

Sum for k=0,…,n-1. The right side telescopes. After applying a sum-to-product identity, obtain

Σ cos(a+kd) = sin(nd/2) cos(a+(n-1)d/2)/sin(d/2),
Σ sin(a+kd) = sin(nd/2) sin(a+(n-1)d/2)/sin(d/2),

for integer n≥1 and sin(d/2)≠0. If d=2mπ, each summand is unchanged and the sums are n cos a and n sin a. The undivided telescoping identities remain valid even when sin(d/2)=0.

## M13 — Product telescoping

Iterating sin 2u=2sin u cos u gives

sin(2^n x)=2^n sin x ∏_(j=0)^(n-1) cos(2^j x), n≥1.

Prove by induction: multiply the n-case by 2cos(2^n x). The undivided version is valid for all real x. A quotient formula for the product requires sin x≠0, or an explicit limiting/exception analysis. This method generates infinitely many certified identities from a short schema.

## M14 — Matrix composition and repeated rotations

After G11/G12, use R(x)=[[cos x,-sin x],[sin x,cos x]]. Exact matrix multiplication gives R(x)R(y)=R(x+y). Induction yields R(x)^n=R(nx), including n=0; negative n additionally requires the independently justified inverse R(-x).

This organizes multiple-angle identities efficiently. It is not an independent proof of addition if R(x)R(y)=R(x+y) was introduced using addition. Keep the geometric composition proof as the foundation and algebraic multiplication as its computed representation.

## M15 — Complex multiplication and de Moivre, optional

After an independent complex or rotation foundation, let z=cos x+i sin x. Multiplication gives z(x)z(y)=z(x+y); induction yields z(x)^n=cos(nx)+i sin(nx) for integer n≥0. Negative n needs z≠0, already certified by its foundation. Expand (c+is)^n and compare real/imaginary parts for explicit multiple-angle polynomials.

Do not invoke de Moivre as a root theorem if its only proof depended on the target identity. The complex route is optional and must not silently broaden the six-function input parser.

## M16 — Roots of unity and equally spaced directions, optional

Let ζ=exp(2πi/n), n≥2, from an independent exponential foundation. Prove ζ^n=1 and ζ≠1, then (1-ζ)Σ_(k=0)^(n-1) ζ^k=1-ζ^n=0, so the sum is zero. Real and imaginary parts give the corresponding cosine and sine sums. For frequency m, Σ exp(2πimk/n) is n when n divides m, otherwise zero. The exceptional divisor case must not be dropped.

The same result has a geometric interpretation: a nonzero vector sum invariant under a nontrivial rotation would have to point in an unchanged direction, impossible. Supply a rigorous rotation argument if claiming a geometry-only route.

## M17 — Exact coefficient comparison

After certified transformations, a finite trigonometric polynomial can be represented as a Laurent polynomial in z=exp(ix) in the optional complex profile. Prove equality by exact coefficient equality. Conversely, if a finite Laurent polynomial vanishes for all unit-circle points, multiply by a power of z and use that a nonzero polynomial has only finitely many roots.

Sampling finitely many arbitrary points is insufficient. A certified interpolation method can use a known degree bound and enough distinct exact points, but must prove those prerequisites and exact evaluations. Floating-point FFT output is not a certificate.

## M18 — Inequalities from squares and factorization

Use a²≥0, sums of squares, and ordered-field rules with sign guards. For sc≠0,

(tan x-cot x)²≥0 and tan x cot x=1 imply tan²x+cot²x≥2.

Equality requires tan x=cot x, hence sin²x=cos²x, so x=π/4+kπ/2. This includes the domain check. For |sin x|+|cos x|, squaring gives 1+2|sc|, yielding bounds 1 and √2. Equality at the lower bound requires sc=0; at the upper bound requires |s|=|c|.

## M19 — Contradiction, cases and exhaustiveness

Proof by contradiction is valid only when assumptions are tracked and every step is justified; it does not allow assuming the desired equality and stopping after a tautology. Case splits must cover the full domain. Useful splits include zero/nonzero divisor, sign of a square root's argument expression, quadrants, endpoints, degenerate coefficients and integer parity.

For x satisfying sin x=2, G24 gives a contradiction because |sin x|≤1. This is a proof of no solutions. Failure to locate a numerical root is not.

## M20 — Method selection

| Structure | Preferred route | Main guard |
|---|---|---|
| Fundamental norm identity | G01/G03/G04 | No F08 premise |
| Angle addition | G11/G12 | Rotation derived independently |
| Rational same-angle expression | M02–M06 | Denominator ledger |
| Integer multiple angles | M08/M09 | Integer typing, base cases |
| High even powers | M10 | Certified circle relation |
| Mixed rational trig equation | M11 | Missing odd-π branch |
| Arithmetic-progression sums | M12 | Zero step-sine branch |
| Products of doubled angles | M13 | Do not divide away zeros |
| Symmetric finite-angle sums | M16 | Frequency/divisibility cases |
| Bounds and impossibility | G24/M18 | Equality cases and signs |

Search should prioritize short proofs with small trusted bases, few new conditions and minimal case splitting. “Fewest identities” alone is not a soundness criterion.

# v0.5 — Optional analytic proof methods

These modules are deliberately separate from the geometry core. The earlier six-function scope did not include calculus or complex functions. The present request for other useful proof methods motivates documenting them; enabling them in software requires parser, type, rule-checker and profile work. A mathematical proof printed here is not an implemented Python capability.

## AN01 — Power series as an independent foundation

Under AX.REAL, AX.ANALYSIS and AX.SERIES define

S(x)=Σ_(n≥0) (-1)^n x^(2n+1)/(2n+1)!,
C(x)=Σ_(n≥0) (-1)^n x^(2n)/(2n)!.

The ratio test gives convergence for every real x. On a bounded interval, absolute terms are bounded by the corresponding positive series at a fixed bound M; this yields uniform convergence. The differentiated series satisfy the analogous bound. The differentiation theorem therefore permits termwise differentiation, giving S'=C, C'=-S, S(0)=0 and C(0)=1.

D.ANALYTIC_QUOT defines tangent/cotangent/secant/cosecant as the corresponding quotients/reciprocals of S,C, with their nonzero-denominator conditions. It does not import D.UNIT.

This is independent of F08. Proving that these functions equal the geometric sine/cosine requires a bridge: the geometrically parameterized unit circle, with signed arc length in radians, satisfies the same ODE and initial values; uniqueness identifies the functions. Proving that geometric ODE itself needs the relevant arc-length and differentiability results. If the bridge used F08, the series proof remains independent within SERIES but is not automatically an independent GEO proof.

## AN02 — Constant derivative proof of F08

**Dependencies:** AN01, AX.ANALYSIS.

Let H(x)=S(x)²+C(x)². Product rule and the independently established derivatives give H'=2SC+2C(-S)=0. By the mean value theorem H is constant on the connected domain ℝ. Since H(0)=0²+1²=1, H(x)=1 for all real x.

The proof is not circular under AN01. It could be circular if derivative formulas were merely imported from a geometry derivation whose proof required F08. The certificate must expose the derivative provenance, not only write “differentiate.”

## AN03 — Addition formulas by ODE uniqueness

**Dependencies:** AN01 or the ODE definition, AX.ODE.

For fixed y, both pairs

(S(x+y), C(x+y))
and
(S(x)C(y)+C(x)S(y), C(x)C(y)-S(x)S(y))

satisfy u'=v, v'=-u. At x=0 both pairs equal (S(y),C(y)). Uniqueness gives equality for all x, establishing addition without assuming it. Verify both derivatives and both initial conditions exactly. A scalar second-order version likewise needs two initial conditions, not one.

## AN04 — Complex exponential proof of F08

**Dependencies:** AX.COMPLEX, AX.SERIES, AX.ANALYSIS.

Define E(z)=Σ z^n/n! and justify absolute convergence and the Cauchy product. The binomial theorem then gives E(z+w)=E(z)E(w); E(0)=1, so E(z)E(-z)=1. For real x, separate the even/odd terms: E(ix)=C(x)+iS(x), E(-ix)=C(x)-iS(x). Multiply:

1=E(ix)E(-ix)=(C+iS)(C-iS)=C²+S².

Every use of infinite series rearrangement needs absolute convergence. If Euler's formula was originally proved using geometric norm preservation based on F08, merely citing Euler's formula is not an independent route. Here the exponential series is the independent starting point.

## AN05 — Equality by equal derivatives and an initial value

To prove f=g on a connected interval I, prove differentiability on I, f'=g' throughout I, and equality at one point of I. The mean value theorem applied to f-g completes the proof. On a disconnected domain, establish the constant on each component or use a separate symmetry/periodicity argument connecting them.

Example: a derivative comparison for expressions involving tan x cannot use x=0 alone to establish equality on every interval separated by poles. Such a proof establishes only the component containing 0 unless the other components are handled.

## AN06 — Integral representation

From AN01 and the fundamental theorem of calculus, S(x)=∫₀ˣ C(t)dt and C(x)=1-∫₀ˣ S(t)dt. Integration by parts and changes of variables can prove identities involving integrals of trig products, provided integrability and boundaries are checked.

Example: after product-to-sum is independently available, ∫₀^(2π) sin(mx)sin(nx)dx is 0 for distinct positive integers m,n and π when m=n. The m=n branch uses sin²(nx)=(1-cos(2nx))/2; dividing by m-n without separating that case is invalid. Cosine products have the analogous positive-integer result, while a constant-frequency term needs its own normalization.

Integration is helpful for orthogonality and coefficient uniqueness, not a shortcut to assuming the product-to-sum identity being proved.

## AN07 — Continuity and removable intermediate gaps

Suppose L and R are defined and continuous on D, and a proof gives equality on a dense subset E of D. For p∈D, choose a sequence in E approaching p and take limits to obtain L(p)=R(p). For a finite set of omitted points, direct substitution is often simpler.

This cannot extend sin x/sin x to x=0 as an identity of the original expressions, because the original left side is undefined there. It can establish an independent continuous extension, but that is a NEW function and must be labelled as such. Likewise, agreement on an open interval does not extend arbitrary continuous functions to all real arguments; density or another theorem is needed.

## AN08 — Series coefficient comparison and analytic continuation

For convergent power series with a common neighbourhood of convergence, exact coefficient equality gives equality there. For complex analytic functions, an identity theorem can extend equality on a set with an interior accumulation point to a connected analytic domain. Check analyticity, connectedness and absence of poles; matching finitely many Taylor coefficients is insufficient.

A finite-order Taylor approximation, small residual, or high-precision numerical test is not an exact identity proof. A real-analytic version also requires a stated analytic domain. Branch-sensitive functions such as principal square roots cannot be treated as globally analytic without branch analysis.

## AN09 — Inequalities from derivatives, convexity and integrals

For 0≤x≤π/2, geometric/analytic estimates can establish sin x≤x≤tan x, with tan undefined at π/2 so the upper comparison is restricted to x<π/2. In the analytic profile, derivative arguments use (x-sin x)'=1-cos x≥0 and (tan x-x)'=tan²x≥0 once the relevant derivatives and norm identity are independently established. Equality occurs at x=0.

Convexity/concavity, Jensen and integral bounds can solve inequality problems, but each needs its interval, sign and strictness assumptions. They should not be used to prove a target from derivative or range theorems whose only proof already used that target.

## AN10 — Limits of automation

Algebraic identities in finitely many integer-angle trig functions often reduce to exact polynomial problems after certified expansions. Arbitrary transcendental equations, mixed frequencies, parameters, inverse branches and inequalities require stronger methods; a finite rule engine cannot promise a complete solver for every input. Certified root isolation can return intervals and counts under explicit monotonicity/error bounds. Uncertified numerical roots must be labelled approximate and incomplete unless a completeness argument is supplied.

The correct fallback is a precise account of what was established, which obligations remain, and why the requested proof or complete solution set is still inconclusive.

# v0.5 — Equation solving and worked proof obligations

## EQ01 — Solution-set contract

An equation solver must prove BOTH:

1. Necessity: every solution of the original equation belongs to the candidate families.
2. Sufficiency: every retained candidate satisfies the original equation and its domain.

Original-domain restrictions are permanent. Track steps as equivalences or one-way implications. Squaring, multiplying by a potentially zero factor, and replacing a variable by a non-surjective chart are especially important. Declare integer parameters explicitly and include interval endpoints correctly.

## EQ02 — Basic sine/cosine/tangent families without inverse syntax

| Equation | Exact real solution description |
|---|---|
| sin x=k, \|k\|>1 | No solutions, by the unit-circle bound |
| sin x=k, -1≤k≤1 | Choose the unique α∈[-π/2,π/2] with sin α=k; x=α+2nπ or x=π-α+2nπ |
| cos x=k, \|k\|>1 | No solutions |
| cos x=k, -1≤k≤1 | Choose the unique α∈[0,π] with cos α=k; x=±α+2nπ |
| tan x=k, k real | Choose the unique α∈(-π/2,π/2) with tan α=k; x=α+nπ |
| cot x=k, k real | Choose the unique α∈(0,π) with cot α=k; x=α+nπ |

Here n∈ℤ. Existence, uniqueness and completeness follow from circle intersections and monotonicity on the specified arcs. At k=±1 for sine/cosine, duplicate families must be merged. Inverse notation asin, acos and atan is optional shorthand with exactly these ranges. There is no branch-free global inverse sine.

For sec x=k, k=0 is impossible; if k≠0 solve cos x=1/k and require |k|≥1. For csc x=k solve sin x=1/k with the same range test. These solutions automatically avoid the corresponding zero denominator, but the check should still be recorded.

## EQ03 — Affine arguments and degenerate coefficients

To solve sin(ax+b)=k with a≠0, solve for the argument u=ax+b by EQ02, then x=(u-b)/a. For a=0, evaluate the constant sin b: either every real x satisfies the equation or none do. Analogous rules hold for the other functions, subject to the constant expression being defined.

On [L,U], determine all integers in each family x=p+nq. If q>0, use ceil((L-p)/q)≤n≤floor((U-p)/q), adjusting open endpoints. If q<0, normalize the family or reverse the bounds correctly. A floating-point near-integer is not an exact endpoint decision.

## EQ04 — Equal trig functions

From G28:

- sin u=sin v iff u=v+2nπ or u=π-v+2nπ.
- cos u=cos v iff u=v+2nπ or u=-v+2nπ.
- tan u=tan v iff u=v+nπ AND both cosines are nonzero.
- cot u=cot v iff u=v+nπ AND both sines are nonzero.

For functional arguments u(x),v(x), solve each resulting equation in x. Do not confuse the integer branch parameter with a real free variable. If a branch becomes an identity after rearrangement, check its remaining domain instead of dividing by zero.

## EQ05 — Factoring without losing roots: sin 2x=sin x

All real x are in the original domain. G21 gives 2sin x cos x=sin x, hence sin x(2cos x-1)=0. Thus sin x=0 or cos x=1/2:

x=nπ, or x=±π/3+2nπ, n∈ℤ.

Every transformation was equivalent; substitution into the factored form and certified double-angle identity proves sufficiency. Dividing by sin x would lose the first family.

## EQ06 — Squaring with rejection: sin x+cos x=1

Squaring gives 1+2sin x cos x=1, hence sin 2x=0, so candidates x=nπ/2. This was a one-way implication. Evaluate by n modulo 4: x=0 mod 2π gives 1; π/2 mod 2π gives 1; π and 3π/2 mod 2π give -1. Therefore the exact solutions are x=2nπ or x=π/2+2nπ.

An alternative equivalent route factors after a phase shift. The solver must not report all nπ/2 solely from the squared equation.

## EQ07 — A canceled denominator: sin x/(1-cos x)=0

Original domain: cos x≠1, so x≠2nπ. A fraction with nonzero denominator is zero exactly when its numerator is zero. Thus sin x=0 gives x=nπ; exclude the even multiples. Solutions: x=(2n+1)π. Using a half-angle chart that omits odd multiples of π and forgetting its missing point would lose EVERY solution in this example.

## EQ08 — Half-angle chart with an omitted solution: sin x=0

Under t=tan(x/2), the finite chart gives 2t/(1+t²)=0, so t=0, corresponding to x=2nπ. The omitted point x=(2n+1)π satisfies the original equation. Union the two families to get x=nπ. This example must be an acceptance test for every half-angle solver.

## EQ09 — Equal squares: sin²x=cos²x

By G21, cos 2x=0. Therefore 2x=π/2+nπ and x=π/4+nπ/2. Alternatively factor (sin x-cos x)(sin x+cos x)=0 and keep BOTH signs. Taking square roots and claiming sin x=cos x alone loses half the roots.

## EQ10 — Linear combination: a sin x+b cos x=c

If a=b=0, return all real x when c=0, otherwise no solutions. For R=√(a²+b²)>0 choose φ by cos φ=a/R, sin φ=b/R. Then R sin(x+φ)=c by G23. If |c|>R, no solution. If |c|≤R choose α∈[-π/2,π/2] with sin α=c/R. The solutions are

x=α-φ+2nπ or x=π-α-φ+2nπ.

At |c|=R the two families coincide. This supplies necessity and sufficiency because phase reduction is an identity and the sine classification is complete.

Worked example: 3sin x+4cos x=6 has no solution since its amplitude is 5. This is exact, not a numerical failure to find roots.

## EQ11 — Tangent equations with domain checks

For tan 2x=tan x require cos 2x cos x≠0. EQ04 gives 2x=x+nπ, hence x=nπ. Each candidate satisfies both nonzero conditions and the original equation, so the family is complete.

For tan x=sin x/cos x, every x with cos x≠0 is a solution because it is a defining equality on that domain. Points x=π/2+nπ are undefined, not additional roots. A solver should distinguish an equation true everywhere on its domain from a finite or periodic discrete root set.

## EQ12 — Polynomial substitution with range constraints

For 2sin²x-3sin x+1=0, put s=sin x and require -1≤s≤1. Factor (2s-1)(s-1)=0. Thus sin x=1/2 or sin x=1. Solutions are x=π/6+2nπ, 5π/6+2nπ, or π/2+2nπ.

If a polynomial produces s=2, reject it using the range constraint. For a substitution t=tan x, t ranges over all real values but x excludes poles. For s²=sin²x, retain 0≤s²≤1 and reconstruct both signs where required.

## EQ13 — Radicals and absolute values

To solve √(1-cos²x)=sin x, use G04 and the principal-root rule to obtain |sin x|=sin x. This holds exactly when sin x≥0, i.e. x∈[2nπ,(2n+1)π] for some integer n. It is a union of intervals, not a discrete set.

For √f(x)=g(x), require f(x)≥0 and g(x)≥0. Then and only then is it equivalent to f(x)=g(x)². Record original domain even if the squared equation appears simpler.

## EQ14 — Conditional triangle equation

For A,B,C∈(0,π), A+B+C=π, and cos A cos B cos C≠0, the tangent-sum relation in G26 is an identity under those assumptions. If the problem instead asks to find A,B,C from that relation alone, the converse is not automatic: tan periodicity allows other angle sums. The triangle-angle and interval constraints must be used to establish any converse.

## EQ15 — Products and sums with several angle branches

Example: cos x=cos 3x. EQ04 gives x=3x+2nπ or x=-3x+2nπ, hence x=-nπ or x=nπ/2. The first family is contained in the second, so the complete set is x=nπ/2. A product-to-sum proof gives 2sin 2x sin x=0 and the same union. Deduplicate families by exact integer arithmetic, not approximate root clustering.

## EQ16 — A rational identity versus a rational equation

Claim: (1-cos x)/sin x=sin x/(1+cos x). Original common domain is sin x≠0; the equation is true throughout that domain. Cross-multiplication gives 1-cos²x=sin²x, valid for every real x, but the transformed equality has a larger domain. The solution set of the original equation is still ℝ\{nπ:n∈ℤ}.

If asked only whether the equality is an identity, conclude PROVED on that original common domain. If asked to solve it, return the full domain as the solution set. Neither mode permits adding undefined angles.

## EQ17 — Parameter branches and geometric degeneracy

For a sin x=b, separate a=0 before division. If a≠0, test |b/a|≤1. For line-circle constructions, separate zero normal vector before computing distance |c|/√(a²+b²). For a quadratic substitution, separate a zero leading coefficient before applying the quadratic formula. If a discriminant is zero, merge repeated roots. These are logical branches, not numerical tolerances.

## EQ18 — Exact and numerical solutions

Some equations have no elementary closed-form family. A complete exact answer may use a set defined by certified roots on a fundamental interval plus periodic shifts, provided periodicity and root completeness are proved. Certified intervals with interval arithmetic can establish root existence/uniqueness under suitable conditions. Plain numerical approximations may be useful but must be labelled approximate, and incompleteness must remain explicit.

A numerical counterexample to an identity should ideally be replaced by an exact value or a rigorous interval separating the sides. Close floating-point disagreement near a pole is not reliable evidence by itself.

## Additional fully worked identity examples

### W5A — F08, the original reported problem

Construct P=(cos x,sin x) on the circle of radius 1. Its horizontal/vertical projection lengths are |cos x| and |sin x|. G01 gives their squared sum as OP². Hence sin²x+cos²x=1 for all real x, with axis cases from G03. Dependency route: G01 → G03 → G04; F08 is never an assumed theorem.

### W5B — F09 from the independently proved F08

On cos x≠0, divide G04 by cos²x:

sin²x/cos²x+1=1/cos²x.

By quotient/reciprocal definitions this is tan²x+1=sec²x. The route is noncircular for F09. It is NOT an independent route for F08 unless the geometric F08 subproof is expanded, in which case that subproof already establishes the target.

### W5C — All-angle addition

Let P=(cos x,sin x). From the independently derived basis rotation G11,

R_y(P)=(cos x cos y-sin x sin y, sin x cos y+cos x sin y).

The same geometric rotation produces the point at angle x+y. Equating its two coordinates proves both cosine and sine addition on ℝ². No tangent ratios, acute-angle assumption or F08 simplifier is required.

### W5D — Domain-safe double-angle quotient

Prove sin 2x/(1+cos 2x)=tan x. The common domain is cos x≠0, since 1+cos 2x=2cos²x by certified G21. Substitute:

sin 2x/(1+cos 2x)=2sin x cos x/(2cos²x)=sin x/cos x=tan x.

The nonzero cancellation is justified by the original common domain. At x=π/2 the left and right are both undefined, so no extension is claimed.

### W5E — A high-power identity with a small algebra certificate

Let s=sin x,c=cos x and h=s²+c²-1. Exact polynomial expansion gives

s⁴+c⁴-(1-2s²c²)=h(s²+c²+1).

G04 gives h=0, so sin⁴x+cos⁴x=1-2sin²x cos²x. G21 optionally replaces 2s²c² by sin²2x/2. All expressions are defined for all real x.

### W5F — A false claim is not a proof request to satisfy

sin(x+y)=sin x+sin y is false. At x=y=π/2, the left side is sin π=0 and the right side is 2. The exact axis values from G09/G10 give a counterexample. Do not search for a route that assumes a contradictory premise merely to display PROVED.

# Six-Function Trigonometric Proof Engine

> **Scope.** A reusable, self-contained proof skill for real-angle expressions built from **only** `sin`, `cos`, `tan`, `cot`, `sec`, and `csc`, together with real constants, arithmetic, radicals, and angle combinations. No inverse, hyperbolic, exponential, or complex trigonometric functions are needed. The collection is **broad rather than literally exhaustive**: infinitely many identities and proofs can be generated from the six functions.

## 0. Operational instructions for an assistant

When asked to prove a trigonometric identity:

1. **Parse the statement exactly.** Record both sides, angle variables, stated restrictions, and whether it is an identity, conditional equality, equation, or inequality.
2. **Determine the original domain** before manipulating anything. State where every original denominator and every `tan`, `cot`, `sec`, or `csc` is defined. If radicals occur, also require real radicands and nonzero radical denominators.
3. **Check plausibility.** Test simple permissible angles or use the identities below. If the claim is false, provide a valid counterexample rather than a fabricated proof.
4. **Prefer a one-sided proof:** transform the more complicated side into the other without assuming the conclusion. If a two-sided reduction is shorter, reduce both sides to the same third expression.
5. **Use the least powerful suitable tool:** reciprocal/quotient/Pythagorean identities → common denominators and factoring → angle formulas → product-to-sum → substitutions or auxiliary identities.
6. **Show the decisive steps.** Cite database IDs where helpful; explicitly identify any cancellation, factoring, conjugate, or angle formula.
7. **Preserve domain logic.** Multiplying by a possibly zero expression, canceling factors, taking square roots, and squaring equations can change the solution set. A derived formula can have a smaller domain than the original identity.
8. **Conclude with a precise statement:** equality holds for every real angle in the original common domain, or state additional restrictions if the proof used them.
9. **If a problem asks for a particular method**, use it if valid (e.g., LHS-only, RHS-only, unit circle, angle addition, without converting all to sine/cosine).
10. **Never claim an identity at a point where one side is undefined.** Equal limits do not make an undefined expression defined.

### Default response format

**Claim:** write the exact identity. **Domain:** list restrictions. **Proof:** a logically ordered sequence of equalities with short justifications. **Conclusion:** identity verified on its common domain. For false claims, replace the proof with **Counterexample** and optionally a corrected identity.

### Notation

- Angles `x,y,z,A,B,C` are real; use radians unless a degree symbol is written.
- `sin²x` means `(sin x)²`; `sin 2x` means `sin(2x)`, not `(sin x)²`.
- `k ∈ ℤ`; `π` is the usual half-turn; `√` is the **nonnegative** real square root.
- `D(E)` denotes the real domain on which expression `E` is defined.
- An identity `L=R` means equality for all real assignments in `D(L) ∩ D(R)`; this **does not** assert that the two sides have identical domains.
- A reference to a denominator being nonzero includes denominators embedded in compound fractions.

# PART I — FOUNDATIONS AND MASTER IDENTITY INDEX

## 1. The six elementary functions and their domains

| Function | Definition from sine and cosine | Undefined when | Zeros (when defined) |
|---|---|---|---|
| `sin x` | unit-circle vertical coordinate | never | `x=kπ` |
| `cos x` | unit-circle horizontal coordinate | never | `x=π/2+kπ` |
| `tan x` | `sin x / cos x` | `cos x=0` | `x=kπ` |
| `cot x` | `cos x / sin x` | `sin x=0` | `x=π/2+kπ` |
| `sec x` | `1 / cos x` | `cos x=0` | never |
| `csc x` | `1 / sin x` | `sin x=0` | never |

**Geometric foundation:** For a point `(cos x, sin x)` on the unit circle, the radius is one, so `cos²x + sin²x = 1`. Signed rotation and reflection of the point yield the addition, parity, periodicity, and cofunction rules. Quotient and reciprocal definitions generate the other four functions.

### 1.1 Domain ledger

| Expression | Required condition |
|---|---|
| `1/sin x`, `cot x`, `csc x` | `sin x ≠ 0` |
| `1/cos x`, `tan x`, `sec x` | `cos x ≠ 0` |
| `1/tan x` | `sin x ≠ 0` **and** `cos x ≠ 0` |
| `1/cot x` | `sin x ≠ 0` **and** `cos x ≠ 0` |
| `1/(1−cos x)` | `cos x ≠ 1` |
| `1/(1+cos x)` | `cos x ≠ −1` |
| `1/(1−sin x)` | `sin x ≠ 1` |
| `1/(1+sin x)` | `sin x ≠ −1` |
| `√((1−cos x)/2)` | always real, but the square root alone is `\|sin(x/2)\|` |
| `√((1+cos x)/2)` | always real, but the square root alone is `\|cos(x/2)\|` |

**Domain trap:** `tan x · cot x = 1` only when **both** functions exist (`sin x cos x ≠ 0`), whereas `sin x · csc x = 1` requires only `sin x ≠ 0`.

# PART II — DERIVATION BANK (EXPLICIT PROOFS)

The entries below provide **reusable proofs**, not merely formula statements. A formula in Part I can be invoked only after its selected independent proof certificate and domain have been checked. The prose B-entries are explanations, not executable certificates.

## 3. Foundational proofs (B01–B16)

**B01 — Pythagorean identity (F08).** The unit-circle point `(cos x,sin x)` has distance 1 from the origin, hence `cos²x+sin²x=1`.

**B02 — Tangent Pythagorean identity (F09).** Divide B01 by `cos²x` (requiring `cos x≠0`): `1+sin²x/cos²x=1/cos²x`, i.e. `1+tan²x=sec²x`.

**B03 — Cotangent Pythagorean identity (F10).** Divide B01 by `sin²x` (requiring `sin x≠0`): `cos²x/sin²x+1=1/sin²x`, i.e. `cot²x+1=csc²x`.

**B04 — Reciprocal pair (F05).** `tan x cot x=(sin x/cos x)(cos x/sin x)=1`, provided `sin x cos x≠0`.

**B05 — Tangent-plus-cotangent (F15).** `tan x+cot x=(sin²x+cos²x)/(sin x cos x)=1/(sin x cos x)=sec x csc x`.

**B06 — Secant–tangent conjugates (F16).** `(sec x−tan x)(sec x+tan x)=sec²x−tan²x=1` by B02.

**B07 — Cosecant–cotangent conjugates (F17).** `(csc x−cot x)(csc x+cot x)=csc²x−cot²x=1` by B03.

**B08 — Secant and cosecant square sum (F13).** `sec²x+csc²x=(sin²x+cos²x)/(sin²x cos²x)=1/(sin²x cos²x)=sec²x csc²x`.

**B09 — Square of tangent-plus-cotangent (F14).** `(tan x+cot x)²=tan²x+cot²x+2=(sec x csc x)²` by B05.

**B10 — Complementary tangent and cotangent (S12).** `tan(π/2−x)=sin(π/2−x)/cos(π/2−x)=cos x/sin x=cot x` when `sin x≠0`.

**B11 — Complementary secant and cosecant (S13).** `sec(π/2−x)=1/sin x=csc x` when `sin x≠0`.

**B12 — Odd tangent and even secant (S02/S03).** `tan(−x)=sin(−x)/cos(−x)=−tan x`; `sec(−x)=1/cos(−x)=sec x`.

**B13 — Addition formula for sine (A01).** Rotating the unit-circle point `(cos x,sin x)` through `y` produces vertical coordinate `sin x cos y+cos x sin y`; it is also `sin(x+y)`.

**B14 — Addition formula for cosine (A03).** The same rotation produces horizontal coordinate `cos x cos y−sin x sin y`, which equals `cos(x+y)`.

**B15 — Subtraction formulas (A02/A04).** Substitute `−y` into B13/B14, then use `sin(−y)=−sin y`, `cos(−y)=cos y`.

**B16 — Tangent addition (A05).** `tan(x+y)=sin(x+y)/cos(x+y)=(sin x cos y+cos x sin y)/(cos x cos y−sin x sin y)`; divide numerator and denominator by `cos x cos y` (nonzero) to obtain `(tan x+tan y)/(1−tan x tan y)`.

## 4. Angle-formula proofs (B17–B36)

**B17 — Tangent subtraction (A06).** Apply B16 with `−y` and `tan(−y)=−tan y`.

**B18 — Cotangent addition (A07).** `cot(x+y)=cos(x+y)/sin(x+y)`. Divide the quotient from A03/A01 by `sin x sin y` to obtain `(cot x cot y−1)/(cot x+cot y)`; require `sin x sin y sin(x+y)≠0`.

**B19 — Cotangent subtraction (A08).** Substitute `−y` in the sine/cosine subtraction formulas and divide by `sin x sin y`: `(cot x cot y+1)/(cot y−cot x)`.

**B20 — Sine double-angle (D01).** A01 with `y=x`: `sin 2x=sin x cos x+cos x sin x=2sin x cos x`.

**B21 — Three cosine double-angle forms (D02–D04).** A03 with `y=x` gives `cos 2x=cos²x−sin²x`. Replace `cos²x` by `1−sin²x` for D03; replace `sin²x` by `1−cos²x` for D04.

**B22 — Tangent double-angle (D05).** Apply A05 with `y=x`: `tan 2x=2tan x/(1−tan²x)` on its stated domain.

**B23 — Cotangent double-angle (D06).** Apply A07 with `y=x`: `cot 2x=(cot²x−1)/(2cot x)`; this representation requires `sin x cos x≠0`.

**B24 — Sine triple-angle (D07).** `sin 3x=sin(2x+x)=sin 2x cos x+cos 2x sin x=2sin x cos²x+(1−2sin²x)sin x=3sin x−4sin³x`.

**B25 — Cosine triple-angle (D08).** `cos 3x=cos(2x+x)=cos 2x cos x−sin 2x sin x=(2cos²x−1)cos x−2sin²x cos x=4cos³x−3cos x`.

**B26 — Tangent triple-angle (D09).** Apply A05 to `tan(2x+x)`, insert D05, and simplify to `(3t−t³)/(1−3t²)` for `t=tan x`. This is valid whenever `cos x cos 3x≠0`; at an intermediate point with `cos 2x=0`, use direct sine/cosine expansion instead of the `tan 2x` intermediate.

**B27 — Cotangent triple-angle (D10).** From B24–B25, `cot 3x=(4cos³x−3cos x)/(3sin x−4sin³x)`. Divide numerator and denominator by `sin³x` to obtain `(cot³x−3cot x)/(3cot²x−1)` wherever `sin x sin 3x≠0`.

**B28 — Sine quadruple-angle (D11).** `sin 4x=2sin 2x cos 2x=4sin x cos x(cos²x−sin²x)`.

**B29 — Cosine quadruple-angle (D12).** `cos 4x=1−2sin²2x=1−8sin²x cos²x`.

**B30 — Sine recurrence (D13).** Add `sin((n+1)x)=sin(nx)cos x+cos(nx)sin x` and `sin((n−1)x)=sin(nx)cos x−cos(nx)sin x`; rearrange.

**B31 — Cosine recurrence (D14).** Add `cos((n+1)x)=cos(nx)cos x−sin(nx)sin x` and `cos((n−1)x)=cos(nx)cos x+sin(nx)sin x`; rearrange.

**B32 — Sine polynomial recurrence (D15).** Base cases: `sin x=sin x U_0(cos x)`, `sin 2x=sin x U_1(cos x)`. B30 proves the polynomial recurrence inductively.

**B33 — Cosine polynomial recurrence (D16).** Base cases: `cos 0=1=T_0(cos x)` and `cos x=T_1(cos x)`; B31 proves the polynomial recurrence inductively.

**B34 — Sine and cosine of an angle difference.** `sin(x−y)=sin x cos y−cos x sin y`; `cos(x−y)=cos x cos y+sin x sin y` follow from B15, and are safe even when tangent is undefined.

**B35 — Difference-of-squares in shifted sine (A13).** Multiply A01 and A02: `(sin x cos y+cos x sin y)(sin x cos y−cos x sin y)=sin²x cos²y−cos²x sin²y=sin²x−sin²y`.

**B36 — Difference-of-squares in shifted cosine (A14/A15).** Multiply A03 and A04: `cos²x cos²y−sin²x sin²y=cos²x−sin²y=cos²x+cos²y−1`.

## 5. Product, sum, half-angle, and phase proofs (B37–B58)

**B37 — Product `2sin x cos y` (P01).** Add A01 and A02: `sin(x+y)+sin(x−y)=2sin x cos y`.

**B38 — Product `2cos x sin y` (P02).** Subtract A02 from A01: `sin(x+y)−sin(x−y)=2cos x sin y`.

**B39 — Product `2cos x cos y` (P03).** Add A03 and A04: `cos(x+y)+cos(x−y)=2cos x cos y`.

**B40 — Product `2sin x sin y` (P04).** Subtract A03 from A04: `cos(x−y)−cos(x+y)=2sin x sin y`.

**B41 — Sum of two sines (P05).** Put `u=(x+y)/2`, `v=(x−y)/2` in P01: `sin x+sin y=sin(u+v)+sin(u−v)=2sin u cos v`.

**B42 — Difference of two sines (P06).** Use `u=(x+y)/2`, `v=(x−y)/2` in P02: `sin x−sin y=2cos u sin v`.

**B43 — Sum of two cosines (P07).** Use the same `u,v` in P03: `cos x+cos y=2cos u cos v`.

**B44 — Difference of two cosines (P08).** Use P04 and reverse order: `cos x−cos y=−2sin u sin v`.

**B45 — Sine half-angle square (H01).** `cos x=1−2sin²(x/2)` by D03 with input `x/2`. Rearrange.

**B46 — Cosine half-angle square (H02).** `cos x=2cos²(x/2)−1` by D04 with input `x/2`. Rearrange.

**B47 — Half-angle tangent, first form (H05).** `sin x/(1+cos x)=2sin(x/2)cos(x/2)/(2cos²(x/2))=tan(x/2)` if `cos(x/2)≠0`.

**B48 — Half-angle tangent, second form (H06).** `(1−cos x)/sin x=2sin²(x/2)/(2sin(x/2)cos(x/2))=tan(x/2)` when `sin x≠0`.

**B49 — Half-angle cotangent (H08/H09).** Invert H06 or H05 only on a domain where the relevant numerator is nonzero, or use the double-angle expansions directly.

**B50 — Power reduction for sine (H10).** Rearrange `cos 2x=1−2sin²x`.

**B51 — Power reduction for cosine (H11).** Rearrange `cos 2x=2cos²x−1`.

**B52 — Sine fourth power (H13).** `sin⁴x=[(1−cos 2x)/2]²=[1−2cos 2x+(1+cos 4x)/2]/4=(3−4cos 2x+cos 4x)/8`.

**B53 — Cosine fourth power (H14).** Similarly `cos⁴x=[(1+cos 2x)/2]²=(3+4cos 2x+cos 4x)/8`.

**B54 — Mixed fourth power (H15).** `sin²x cos²x=(sin²2x)/4=(1−cos 4x)/8`.

**B55 — Tangent-half-angle substitution (H16/H17).** With `t=tan(x/2)`, `sin x=2sin(x/2)cos(x/2)=2t/(1+t²)` and `cos x=cos²(x/2)−sin²(x/2)=(1−t²)/(1+t²)`. Obtain H18–H21 using quotient and reciprocal identities with their extra restrictions.

**B56 — Amplitude-phase for sine (P11).** Let `R=√(a²+b²)>0` and choose `cos φ=a/R`, `sin φ=b/R`. Then `R sin(x+φ)=R sin x cos φ+R cos x sin φ=a sin x+b cos x`.

**B57 — Amplitude-phase for cosine (P12).** Let `cos φ=a/R`, `sin φ=b/R`; `R cos(x−φ)=R cos x cos φ+R sin x sin φ=a cos x+b sin x`.

**B58 — Special 15° and 75° values.** Use `π/12=π/4−π/6` and `5π/12=π/4+π/6` in A01/A03/A05, then simplify radicals; `tan(π/12)=(1−1/√3)/(1+1/√3)=2−√3`.

## 6. Rationalization and compound reciprocal proofs (B59–B80)

**B59 — Cosine-conjugate fraction (R01).** `(1−cos x)/sin x=[(1−cos x)(1+cos x)]/[sin x(1+cos x)]=sin²x/[sin x(1+cos x)]=sin x/(1+cos x)`, for `sin x≠0`.

**B60 — Complementary cosine-conjugate fraction (R02).** `(1+cos x)/sin x=[(1−cos²x)]/[sin x(1−cos x)]=sin x/(1−cos x)`, for `sin x≠0`.

**B61 — Sine-conjugate fraction (R03).** `(1−sin x)/cos x=[(1−sin²x)]/[cos x(1+sin x)]=cos x/(1+sin x)`, for `cos x≠0`.

**B62 — Complementary sine-conjugate fraction (R04).** `(1+sin x)/cos x=cos x/(1−sin x)` by the same method, for `cos x≠0`.

**B63 — Reciprocal of `sec+tan` (R05).** `1/(sec x+tan x)=(sec x−tan x)/(sec²x−tan²x)=sec x−tan x`; `sec x+tan x` cannot vanish because its conjugate product is 1.

**B64 — Reciprocal of `csc+cot` (R06).** `1/(csc x+cot x)=csc x−cot x` because `csc²x−cot²x=1`.

**B65 — Square of `sec+tan` (R07).** `(sec x+tan x)²=[(1+sin x)/cos x]²=(1+sin x)²/(1−sin²x)=(1+sin x)/(1−sin x)`.

**B66 — Square of `csc+cot` (R08).** `(csc x+cot x)²=[(1+cos x)/sin x]²=(1+cos x)/(1−cos x)`.

**B67 — Square of `sec−tan` (R09).** `(sec x−tan x)²=(1−sin x)²/(1−sin²x)=(1−sin x)/(1+sin x)`.

**B68 — Square of `csc−cot` (R10).** `(csc x−cot x)²=(1−cos x)²/(1−cos²x)=(1−cos x)/(1+cos x)`.

**B69 — Secant-plus-one ratio (R11).** `tan x/(sec x+1)=[sin x/cos x]/[(1+cos x)/cos x]=sin x/(1+cos x)`.

**B70 — Cosecant-plus-one ratio (R12).** `cot x/(csc x+1)=[cos x/sin x]/[(1+sin x)/sin x]=cos x/(1+sin x)`.

**B71 — Reciprocal sine pair, sum (R13).** `1/(1−sin x)+1/(1+sin x)=2/(1−sin²x)=2/cos²x=2sec²x`.

**B72 — Reciprocal cosine pair, sum (R14).** `1/(1−cos x)+1/(1+cos x)=2/(1−cos²x)=2csc²x`.

**B73 — Reciprocal sine pair, difference (R15).** `1/(1−sin x)−1/(1+sin x)=2sin x/cos²x=2tan x sec x`.

**B74 — Reciprocal cosine pair, difference (R16).** `1/(1−cos x)−1/(1+cos x)=2cos x/sin²x=2cot x csc x`.

**B75 — Fraction of tangent and secant (R17).** Since `tan x−sec x=−(sec x−tan x)=−1/(sec x+tan x)`, the ratio is `−(sec x+tan x)²`.

**B76 — Fraction of cotangent and cosecant (R18).** Since `cot x−csc x=−(csc x−cot x)=−1/(csc x+cot x)`, the ratio is `−(csc x+cot x)²`.

**B77 — Secant addition (A18).** `sec(x+y)=1/[cos x cos y−sin x sin y]`. Factor `cos x cos y` from the denominator to obtain `sec x sec y/(1−tan x tan y)` on the stated domain.

**B78 — Secant subtraction (A19).** `sec(x−y)=1/[cos x cos y+sin x sin y]=sec x sec y/(1+tan x tan y)` on the stated domain.

**B79 — Cosecant addition (A20).** `csc(x+y)=1/[sin x cos y+cos x sin y]`. Factor `sin x sin y` from the denominator to obtain `csc x csc y/(cot x+cot y)` on the stated domain.

**B80 — Cosecant subtraction (A21).** `csc(x−y)=1/[sin x cos y−cos x sin y]=csc x csc y/(cot y−cot x)` on the stated domain.

Domain: `cos x≠0`. Proof: denominator equals `sec²x`, which is nonzero.

**W10.** Prove `csc²x/(1+cot²x)=1`.

Domain: `sin x≠0`. Proof: denominator equals `csc²x`, which is nonzero.

Domain: `sin x cos x≠0`. Proof: `(tan x+cot x)sin x cos x=(sin²x+cos²x)=1`.

**W12.** Prove `(tan x+cot x)/(sec x csc x)=1`.

Domain: `sin x cos x≠0`. Proof: F15 gives identical numerator and denominator.

**W13.** Prove `tan²x/(sec x+1)=sec x−1`.

Domain: `cos x≠0` and `sec x+1≠0` (equivalently `cos x≠−1`). Proof: `tan²x=sec²x−1=(sec x−1)(sec x+1)`; cancel the nonzero factor.

**W14.** Prove `cot²x/(csc x+1)=csc x−1`.

Domain: `sin x≠0` and `csc x+1≠0` (equivalently `sin x≠−1`). Proof: `cot²x=csc²x−1=(csc x−1)(csc x+1)`; cancel.

**W15.** Prove `(sec x−1)(sec x+1)=tan²x`.

Domain: `cos x≠0`. Proof: difference of squares `sec²x−1=tan²x`.

**W16.** Prove `(csc x−1)(csc x+1)=cot²x`.

Domain: `sin x≠0`. Proof: `csc²x−1=cot²x`.

**W17.** Prove `sec x−cos x=sin x tan x`.

Domain: `cos x≠0`. Proof: `sec x−cos x=(1−cos²x)/cos x=sin²x/cos x=sin x tan x`.

**W18.** Prove `csc x−sin x=cos x cot x`.

Domain: `sin x≠0`. Proof: `csc x−sin x=(1−sin²x)/sin x=cos²x/sin x=cos x cot x`.

**W19.** Prove `sec x+cos x tan²x=sec x`.

Domain: `cos x≠0`. Proof: `cos x tan²x=sin²x/cos x`; thus `sec x+cos x tan²x=(1+sin²x)/cos x`, **not** `sec x` in general. **This is intentionally a false-claim detector.** Counterexample `x=π/4`: LHS `3√2/2`, RHS `√2`. Correct identity: `sec x−cos x=sin x tan x` (W17).

**W20.** Prove `sec x(1−sin²x)=cos x`.

Domain: `cos x≠0`. Proof: `sec x(1−sin²x)=(1/cos x)cos²x=cos x`.

## 8. Common denominators and conjugates (W21–W38)

**W21.** Prove `sin x/(1+cos x)=(1−cos x)/sin x`.

Domain: `sin x≠0`. Proof: multiply the left by `(1−cos x)/(1−cos x)` to get `sin x(1−cos x)/(1−cos²x)=(1−cos x)/sin x`.

**W22.** Prove `cos x/(1+sin x)=(1−sin x)/cos x`.

Domain: `cos x≠0`. Proof: multiply by `(1−sin x)/(1−sin x)` and use `1−sin²x=cos²x`.

**W23.** Prove `1/(1−sin x)=sec²x+tan x sec x`.

Domain: `cos x≠0`. Proof: `(1+sin x)/(1−sin²x)=(1+sin x)/cos²x=sec²x+tan x sec x`.

**W24.** Prove `1/(1+sin x)=sec²x−tan x sec x`.

Domain: `cos x≠0`. Proof: `(1−sin x)/cos²x=sec²x−tan x sec x`.

**W25.** Prove `1/(1−cos x)=csc²x+cot x csc x`.

Domain: `sin x≠0`. Proof: `(1+cos x)/sin²x=csc²x+cot x csc x`.

**W26.** Prove `1/(1+cos x)=csc²x−cot x csc x`.

Domain: `sin x≠0`. Proof: `(1−cos x)/sin²x=csc²x−cot x csc x`.

**W27.** Prove `sec x+tan x=(1+sin x)/cos x`.

Domain: `cos x≠0`. Proof: `1/cos x+sin x/cos x=(1+sin x)/cos x`.

**W28.** Prove `csc x+cot x=(1+cos x)/sin x`.

Domain: `sin x≠0`. Proof: `1/sin x+cos x/sin x=(1+cos x)/sin x`.

**W29.** Prove `sec x−tan x=cos x/(1+sin x)`.

Domain: `cos x≠0`. Proof: `(1−sin x)/cos x=cos x/(1+sin x)` by R03.

**W30.** Prove `csc x−cot x=sin x/(1+cos x)`.

Domain: `sin x≠0`. Proof: `(1−cos x)/sin x=sin x/(1+cos x)` by R01.

**W31.** Prove `(1+sin x)/(1−sin x)=(sec x+tan x)²`.

Domain: `cos x≠0`. Proof: `[(1+sin x)/cos x]²=(1+sin x)²/(1−sin²x)=(1+sin x)/(1−sin x)`.

**W32.** Prove `(1+cos x)/(1−cos x)=(csc x+cot x)²`.

Domain: `sin x≠0`. Proof: `[(1+cos x)/sin x]²=(1+cos x)²/(1−cos²x)`.

**W33.** Prove `(1−sin x)/(1+sin x)=(sec x−tan x)²`.

Domain: `cos x≠0`. Proof: use R09 or square W29 after simplifying.

**W34.** Prove `(1−cos x)/(1+cos x)=(csc x−cot x)²`.

Domain: `sin x≠0`. Proof: use R10 or square W30 after simplifying.

**W35.** Prove `(sec x+tan x)+(sec x−tan x)=2sec x`.

Domain: `cos x≠0`. Proof: the tangent terms cancel.

**W36.** Prove `(csc x+cot x)−(csc x−cot x)=2cot x`.

Domain: `sin x≠0`. Proof: the cosecant terms cancel.

**W37.** Prove `1/(sec x−tan x)−1/(sec x+tan x)=2tan x`.

Domain: `cos x≠0`. Proof: apply R05 and its conjugate to obtain `(sec x+tan x)−(sec x−tan x)`.

**W38.** Prove `1/(csc x−cot x)+1/(csc x+cot x)=2csc x`.

Domain: `sin x≠0`. Proof: conjugate reciprocity gives `(csc x+cot x)+(csc x−cot x)`.

## 9. Angle addition, multiplication, and factoring (W39–W56)

**W39.** Prove `sin(x+y)+sin(x−y)=2sin x cos y`.

Domain: all real. Proof: expand both sines by A01/A02; `cos x sin y` cancels.

**W40.** Prove `cos(x−y)−cos(x+y)=2sin x sin y`.

Domain: all real. Proof: expand A04 minus A03.

**W41.** Prove `sin(x+y)sin(x−y)=sin²x−sin²y`.

Domain: all real. Proof: multiply the conjugate expansions; use F08.

**W42.** Prove `cos(x+y)cos(x−y)=cos²x−sin²y`.

Domain: all real. Proof: multiply A03 and A04, simplify by F08.

**W43.** Prove `sin 3x/sin x=3−4sin²x`.

Domain: `sin x≠0`. Proof: D07 gives `sin 3x=sin x(3−4sin²x)`; divide.

**W44.** Prove `cos 3x/cos x=4cos²x−3`.

Domain: `cos x≠0`. Proof: D08 gives `cos 3x=cos x(4cos²x−3)`.

**W45.** Prove `sin 3x=sin x(1+2cos 2x)`.

Domain: all real. Proof: `sin x(1+2cos 2x)=sin x[1+2(1−2sin²x)]=3sin x−4sin³x`.

**W46.** Prove `cos 3x=cos x(2cos 2x−1)`.

Domain: all real. Proof: `cos x[2(2cos²x−1)−1]=4cos³x−3cos x`.

**W47.** Prove `sin 2x/(1+cos 2x)=tan x`.

Domain: `cos x≠0`. Proof: `sin 2x/(1+cos 2x)=(2sin x cos x)/(2cos²x)=tan x`.

**W48.** Prove `(1−cos 2x)/sin 2x=tan x`.

Domain: `sin x cos x≠0`. Proof: `(2sin²x)/(2sin x cos x)=tan x`. This representation excludes `sin x=0`, where `tan x` itself is defined.

**W49.** Prove `sin 2x/(1−cos 2x)=cot x`.

Domain: `sin x≠0`. Proof: `(2sin x cos x)/(2sin²x)=cot x`.

**W50.** Prove `(1+cos 2x)/sin 2x=cot x`.

Domain: `sin x cos x≠0`. Proof: `(2cos²x)/(2sin x cos x)=cot x`.

**W51.** Prove `sin²x−sin²y=sin(x+y)sin(x−y)`.

Domain: all real. Proof: rewrite `sin²x−sin²y` as `sin²x(1−sin²y)−sin²y(1−sin²x)` and factor into the conjugate sine expansions.

**W52.** Prove `cos²x−cos²y=−sin(x+y)sin(x−y)`.

Domain: all real. Proof: `cos²x−cos²y=(1−sin²x)−(1−sin²y)=−(sin²x−sin²y)`; use W41.

**W53.** Prove `sin x+sin 3x=2sin 2x cos x`.

Domain: all real. Proof: P05 with angles `x,3x`: `2sin 2x cos(−x)=2sin 2x cos x`.

**W54.** Prove `cos x+cos 3x=2cos 2x cos x`.

Domain: all real. Proof: P07 with angles `x,3x`.

**W55.** Prove `sin 3x−sin x=2cos 2x sin x`.

Domain: all real. Proof: P06 with angles `3x,x`.

**W56.** Prove `cos x−cos 3x=2sin 2x sin x`.

Domain: all real. Proof: P08 with angles `x,3x`: `−2sin 2x sin(−x)=2sin 2x sin x`.

## 10. Multi-function and conditional identities (W57–W76)

**W57.** Prove `sec²x csc²x=(tan x+cot x)²`.

Domain: `sin x cos x≠0`. Proof: both sides equal `1/(sin²x cos²x)` by B05.

**W58.** Prove `tan²x+cot²x=sec²x csc²x−2`.

Domain: `sin x cos x≠0`. Proof: expand `(tan x+cot x)²` and use `tan x cot x=1`.

**W59.** Prove `tan x+cot x=2csc 2x`.

Domain: `sin x cos x≠0`. Proof: `tan x+cot x=1/(sin x cos x)=2/(2sin x cos x)=2csc 2x`.

**W60.** Prove `tan x−cot x=−2cot 2x`.

Domain: `sin x cos x≠0`. Proof: `tan x−cot x=(sin²x−cos²x)/(sin x cos x)=−cos 2x/((sin 2x)/2)=−2cot 2x`.

**W61.** Prove `sec x csc x=2csc 2x`.

Domain: `sin x cos x≠0`. Proof: both sides equal `1/(sin x cos x)`.

**W62.** Prove `(sec x+tan x)(1−sin x)=cos x`.

Domain: `cos x≠0`. Proof: `[(1+sin x)/cos x](1−sin x)=(1−sin²x)/cos x=cos x`.

**W63.** Prove `(csc x+cot x)(1−cos x)=sin x`.

Domain: `sin x≠0`. Proof: `[(1+cos x)/sin x](1−cos x)=sin x`.

**W64.** Prove `(sec x−tan x)(1+sin x)=cos x`.

Domain: `cos x≠0`. Proof: `[(1−sin x)/cos x](1+sin x)=cos x`.

**W65.** Prove `(csc x−cot x)(1+cos x)=sin x`.

Domain: `sin x≠0`. Proof: `[(1−cos x)/sin x](1+cos x)=sin x`.

**W66.** Prove `tan(x+y)(1−tan x tan y)=tan x+tan y`.

Domain: `cos x cos y cos(x+y)≠0`. Proof: multiply A05 by its nonzero denominator.

**W67.** Prove `tan(x−y)(1+tan x tan y)=tan x−tan y`.

Domain: `cos x cos y cos(x−y)≠0`. Proof: multiply A06 by its nonzero denominator.

**W68.** Prove `sin(x+y)cos(x−y)+cos(x+y)sin(x−y)=sin 2x`.

Domain: all real. Proof: A01 applied to `(x+y)+(x−y)=2x`.

**W69.** Prove `sin(x+y)cos(x−y)−cos(x+y)sin(x−y)=sin 2y`.

Domain: all real. Proof: A02 applied to `(x+y)−(x−y)=2y`.

**W70.** Prove `cos(x+y)cos(x−y)−sin(x+y)sin(x−y)=cos 2x`.

Domain: all real. Proof: A03 applied to `(x+y)+(x−y)=2x`.

**W71.** Prove `cos(x+y)cos(x−y)+sin(x+y)sin(x−y)=cos 2y`.

Domain: all real. Proof: A04 applied to `(x+y)−(x−y)=2y`.

**W72.** If `A+B+C=π`, prove `sin(A+B)=sin C`.

Domain: all real `A,B,C` satisfying the condition. Proof: `sin(A+B)=sin(π−C)=sin C`.

**W73.** If `A+B+C=π`, prove `tan A+tan B+tan C=tan A tan B tan C`.

Domain: `cos A cos B cos C≠0`. Proof: `sin(A+B+C)=0`. Expanding via A01 twice gives `sin A cos B cos C+cos A sin B cos C+cos A cos B sin C−sin A sin B sin C=0`. Divide by `cos A cos B cos C`.

**W74.** If `A+B+C=π`, prove `cot A cot B+cot B cot C+cot C cot A=1`.

Domain: `sin A sin B sin C≠0`. Proof: `sin(A+B+C)=0`. Divide the same four-term expansion in W73 by `sin A sin B sin C`, yielding `cot B cot C+cot A cot C+cot A cot B−1=0`.

**W75.** If `A+B+C=π`, prove `cos²A+cos²B+cos²C+2cos A cos B cos C=1`.

Domain: all real `A,B,C` satisfying the condition. Proof: `cos C=−cos(A+B)=sin A sin B−cos A cos B`. Let `p=cos A cos B`, `q=sin A sin B`. Then `cos²C+2p cos C=(q−p)²+2p(q−p)=q²−p²`. Therefore `cos²A+cos²B+cos²C+2p cos C=cos²A+cos²B+sin²A sin²B−cos²A cos²B=1` after using `sin²A=1−cos²A`, `sin²B=1−cos²B`.

**W76.** If `A+B+C=π`, prove `sin 2A+sin 2B+sin 2C=4sin A sin B sin C`.

Domain: all real `A,B,C` satisfying the condition. Proof: `sin 2A+sin 2B=2sin(A+B)cos(A−B)=2sin C cos(A−B)`; `sin 2C=2sin C cos C=−2sin C cos(A+B)`. Add and use `cos(A−B)−cos(A+B)=2sin A sin B`.

## 11. Advanced algebraic and compound-angle patterns (W77–W96)

**W77.** Prove `sin⁴x+cos⁴x=1−(1/2)sin²2x`.

Domain: all real. Proof: `(sin²x+cos²x)²−2sin²x cos²x=1−(1/2)sin²2x`.

**W78.** Prove `sin⁶x+cos⁶x=1−(3/4)sin²2x`.

Domain: all real. Proof: with `a=sin²x`, `b=cos²x`, `a³+b³=(a+b)³−3ab(a+b)=1−3sin²x cos²x`.

**W79.** Prove `sin⁴x−cos⁴x=−cos 2x`.

Domain: all real. Proof: `(sin²x−cos²x)(sin²x+cos²x)=−cos 2x`.

**W80.** Prove `cos⁴x−sin⁴x=cos 2x`.

Domain: all real. Proof: difference of squares and F08.

**W81.** Prove `sin²x cos²y−cos²x sin²y=sin²x−sin²y`.

Domain: all real. Proof: replace `cos²y=1−sin²y` and `cos²x=1−sin²x`; mixed terms cancel.

**W82.** Prove `(sin x+cos x)²=1+sin 2x`.

Domain: all real. Proof: expand to `sin²x+cos²x+2sin x cos x`.

**W83.** Prove `(sin x−cos x)²=1−sin 2x`.

Domain: all real. Proof: expand and use D01.

**W84.** Prove `(sin x+cos x)(sin x−cos x)=−cos 2x`.

Domain: all real. Proof: `sin²x−cos²x=−cos 2x`.

**W85.** Prove `(sin x+cos x)⁴+(sin x−cos x)⁴=2+8sin²x cos²x+2sin²2x`.

Domain: all real. Proof: Let `u=sin x+cos x`, `v=sin x−cos x`; `u²=1+sin 2x`, `v²=1−sin 2x`. Then `u⁴+v⁴=2+2sin²2x=2+8sin²x cos²x`. **The displayed proposed right side double-counts the same term and is false in general.** At `x=π/4`, LHS `4`, proposed RHS `6`. Correct identity: `(sin x+cos x)⁴+(sin x−cos x)⁴=2+2sin²2x`.

**W86.** Prove `sin⁴x+cos⁴x=(3+cos 4x)/4`.

Domain: all real. Proof: W77 gives `1−(1/2)sin²2x=1−(1−cos 4x)/4=(3+cos 4x)/4`.

**W87.** Prove `sin²x cos²x=(1−cos 4x)/8`.

Domain: all real. Proof: `sin²x cos²x=(1/4)sin²2x=(1/8)(1−cos 4x)`.

**W88.** Prove `sin x sin 2x sin 3x=[cos 2x−cos 4x−cos 0+cos 6x]/8`.

Domain: all real. **False-claim detector.** At `x=π/6`, LHS `1/2·√3/2·1=√3/4`, proposed RHS `(1/2−(−1/2)−1+(−1))/8=−1/8`. A correct product-to-sum expansion is `sin x sin 2x sin 3x=[sin 2x+sin 4x−sin 6x]/4`: first use `2sin x sin 3x=cos 2x−cos 4x`, multiply by `sin 2x`, then use P02 on both terms.

**W89.** Prove `sin x sin 2x sin 3x=[sin 2x+sin 4x−sin 6x]/4`.

Domain: all real. Proof: `4sin x sin 2x sin 3x=2sin 2x(cos 2x−cos 4x)=sin 4x−[sin 6x+sin(−2x)]=sin 2x+sin 4x−sin 6x`.

**W90.** Prove `cos x cos 2x cos 3x=[cos 0+cos 2x+cos 4x+cos 6x]/4`.

Domain: all real. Proof: `2cos x cos 3x=cos 4x+cos 2x`; multiply by `2cos 2x`: `4cos x cos 2x cos 3x=cos 6x+cos 2x+cos 4x+1`.

**W91.** Prove `sin x+sin 2x+sin 3x=sin 2x(1+2cos x)`.

Domain: all real. Proof: P05 gives `sin x+sin 3x=2sin 2x cos x`; add `sin 2x`.

**W92.** Prove `cos x+cos 2x+cos 3x=cos 2x(1+2cos x)`.

Domain: all real. Proof: P07 gives `cos x+cos 3x=2cos 2x cos x`; add `cos 2x`.

**W93.** Prove `sec(x+y)(1−tan x tan y)=sec x sec y`.

Domain: `cos x cos y cos(x+y)≠0`. Proof: apply A18 and multiply by its nonzero denominator.

**W94.** Prove `sec(x−y)(1+tan x tan y)=sec x sec y`.

Domain: `cos x cos y cos(x−y)≠0`. Proof: apply A19 and multiply by its nonzero denominator.

**W95.** Prove `csc(x+y)(cot x+cot y)=csc x csc y`.

Domain: `sin x sin y sin(x+y)≠0`. Proof: apply A20 and multiply by its nonzero denominator.

**W96.** Prove `csc(x−y)(cot y−cot x)=csc x csc y`.

Domain: `sin x sin y sin(x−y)≠0`. Proof: apply A21 and multiply by its nonzero denominator.

# PART IV — PROOF STRATEGIES, DECISION RULES, AND FAILURE MODES

## 12. Proof-method routing table

| Symptom in problem | First-choice move | Reference |
|---|---|---|
| Mix of `tan`, `cot`, `sec`, `csc` | Replace by sine/cosine, or apply Pythagorean pairs | F01–F17, B01–B12 |
| `1±sin x` or `1±cos x` in denominators | Multiply by conjugate | R01–R16, B59–B74 |
| `sec x±tan x` or `csc x±cot x` | Multiply paired factors; use difference of squares | F16–F17, R05–R10 |
| Two different denominators | Common denominator; factor `sin²+cos²` | W11, W21–W26 |
| `sin 2x`, `cos 2x` | Double-angle; choose convenient form | D01–D06 |
| `sin 3x`, `cos 3x` | Triple-angle polynomial or factor out sin/cos | D07–D10, W43–W46 |
| `sin x±sin y`, `cos x±cos y` | Sum-to-product | P05–P08 |
| Products `sin x cos y`, `sin x sin y` | Product-to-sum | P01–P04 |
| `sin²x`, `cos²x`, fourth powers | Power reduction | H10–H15, W77–W87 |
| `sin x+cos x` | Square, factor, or phase shift | P09–P12, W82–W84 |
| Expressions involving `x/2` | Half-angle, sign and domain check | H01–H21 |
| `sin(nx)` or `cos(nx)` | Addition and recurrences | D13–D16 |
| `A+B+C=π` | Replace `C=π−A−B` or expand `sin(A+B+C)=0` | W72–W76 |
| Asked to show expression is constant | Rewrite in terms of one trig function and simplify | F08–F10 |
| Equality looks suspicious | Numerical counterexample on common domain, then symbolic verification | Section 14 |
| Need to solve equation, not identity | Factor, enumerate zero cases, check periodic families and exclusions | Section 15 |

### 12.1 Proof discipline

- **LHS-only:** Start with `LHS = ... = RHS`. Do not start by writing `LHS=RHS` and transform it as though it were known true.
- **Common target:** `LHS = T` and separately `RHS = T` is valid.
- **Difference method:** `LHS−RHS=0` is valid if every step is reversible or is a direct simplification on the common domain.
- **Cross-multiplication:** `a/b=c/d` can be reduced to `ad=bc` only where `b≠0` and `d≠0`; reverse reasoning must retain those restrictions.
- **Squaring:** `L=R ⇒ L²=R²`, but `L²=R²` alone allows `L=−R`. Add sign information or check both possibilities.
- **Square roots:** `√(u²)=|u|`, **not** generally `u`.
- **Cancellation:** `ab/ac=b/c` only if `a≠0` and `c≠0`; keep the original domain even after simplifying.
- **Division by trig functions:** `sin x`, `cos x`, `tan x`, etc. may be zero; split into cases if proving an equation involving all possible `x`.
- **Identity vs equation:** An identity holds throughout its domain. An equation may hold only for a subset of angles; do not call a solved equation an identity.

## 13. Domain-safe transformation examples

**E01 — Removable expression hole.** `(sin²x)/sin x=sin x` is an identity only for `sin x≠0`; at `x=0`, the left side is undefined despite the simplified right side being zero.

**E02 — Different domains, same values on overlap.** `(1−cos x)/sin x=sin x/(1+cos x)` on `sin x≠0`; the right expression is defined at `x=0` but the left is not.

**E03 — Division can lose solutions.** `sin x cos x=sin x` implies `sin x(cos x−1)=0`, hence `x=kπ`. Dividing by `sin x` would discard all solutions because every solution has `sin x=0`.

**E04 — Square-root sign.** `√(1−sin²x)=|cos x|`, not always `cos x`; at `x=π`, the square root is `1` while `cos π=−1`.

**E05 — Tangent addition has a hidden hole.** At `x=y=π/4`, `tan x=tan y=1` but `tan(x+y)=tan(π/2)` is undefined, matching the zero denominator `1−tan x tan y=0`.

**E06 — Half-angle ambiguity.** `√((1−cos x)/2)=|sin(x/2)|`; at `x=3π`, the right-hand `sin(3π/2)=−1` while the square root is `1`.

**E07 — Avoid unjustified inverse steps.** From `sin x=sin y`, do not infer `x=y`. Valid families are `x=y+2kπ` or `x=π−y+2kπ`.

**E08 — Trig denominator created by substitution.** Replacing `tan x` with `sin x/cos x` requires `cos x≠0`; do not cancel `cos x` and then enlarge the original domain.

## 14. False identity / hallucination detector

The following are **not** identities. A proof assistant must refuse to prove them and provide a counterexample.

| False claim | Counterexample / correction |
|---|---|
| `sin(x+y)=sin x+sin y` | `x=y=π/2`: LHS `0`, RHS `2`; use A01 |
| `cos(x+y)=cos x+cos y` | `x=y=0`: LHS `1`, RHS `2`; use A03 |
| `tan(x+y)=tan x+tan y` | `x=y=π/6`: LHS `√3`, RHS `2/√3`; use A05 |
| `sin²x=sin(x²)` | `x=π/2`: LHS `1`, RHS generally not `1` |
| `sin²x+cos²x=2` | At `x=0`, LHS `1` |
| `sec²x+tan²x=1` | At `x=π/4`, LHS `3`; correct: `sec²x−tan²x=1` |
| `csc²x+cot²x=1` | At `x=π/4`, LHS `3`; correct: `csc²x−cot²x=1` |
| `√(sin²x)=sin x` | At `x=3π/2`, LHS `1`, RHS `−1` |
| `tan x=1/cot x` everywhere `tan` exists | At `x=0`, `tan x=0` but `cot x` undefined |
| `sin 2x=2sin x` | At `x=π/3`, LHS `√3/2`, RHS `√3`; correct: `2sin x cos x` |
| `cos 2x=2cos x` | At `x=0`, LHS `1`, RHS `2` |
| `sin x/sin x=1` for all real `x` | Undefined at `x=kπ`; valid only for `sin x≠0` |
| `sin x+cos x=1` | At `x=π/4`, LHS `√2` |
| `tan²x=sec²x+1` | At `x=0`, LHS `0`, RHS `2`; correct: `sec²x−1` |
| `sin(x−y)=sin x−sin y` | `x=π/2`, `y=π/6`: LHS `√3/2`, RHS `1/2` |

**Counterexample protocol:** Choose angles where *both* sides are defined; compute exact values where possible; a single mismatch disproves a proposed identity. A numerical agreement at a few angles does **not** prove an identity.

## 15. Equation-solving templates (use only when a problem is an equation)

The following are solution families, not identities:

| Equation | General real solutions |
|---|---|
| `sin x=0` | `x=kπ` |
| `cos x=0` | `x=π/2+kπ` |
| `tan x=0` | `x=kπ` |
| `cot x=0` | `x=π/2+kπ` |
| `sin x=sin y` | `x=y+2kπ` or `x=π−y+2kπ` |
| `cos x=cos y` | `x=2kπ+y` or `x=2kπ−y` |
| `tan x=tan y` | `x=y+kπ`, with both tangents defined |
| `cot x=cot y` | `x=y+kπ`, with both cotangents defined |
| `sin²x=cos²x` | `x=π/4+kπ/2` |
| `sin 2x=0` | `x=kπ/2` |
| `cos 2x=0` | `x=π/4+kπ/2` |
| `tan x=1` | `x=π/4+kπ` |
| `tan x=−1` | `x=−π/4+kπ` |

For more general equations, transform using the proof identities, **factor without dividing away zeros**, enumerate all periodic families, and check against the **original** equation's domain.

## 16. Inequalities derivable from the six functions

These can support proofs of bounds, but they are not equality identities.

| ID | Statement | Proof idea / domain |
|---|---|---|
| I01 | `−1≤sin x≤1`, `−1≤cos x≤1` | unit circle |
| I02 | `0≤sin²x≤1`, `0≤cos²x≤1` | squares and F08 |
| I03 | `\|sin x cos x\|≤1/2` | `\|sin 2x\|≤1` |
| I04 | `\|sin x+cos x\|≤√2` | P09 and I01 |
| I05 | `\|a sin x+b cos x\|≤√(a²+b²)` | P11/P12; `a=b=0` trivial |
| I06 | `sec²x≥1` | F09 on `cos x≠0` |
| I07 | `csc²x≥1` | F10 on `sin x≠0` |
| I08 | `tan²x+cot²x≥2` | for `sin x cos x≠0`, `(tan x−cot x)²≥0` and `tan x cot x=1` |
| I09 | `\|sin x\|+\|cos x\|≥1` | square left; it is `1+2\|sin x cos x\|≥1` |

# PART V — QUALITY ASSURANCE AND EXTENSION RULES

## 18. Validation checklist

Before presenting a final proof, confirm:

- [ ] All six-function expressions and their original domains were parsed correctly.
- [ ] Every substitution is valid on the domain being considered.
- [ ] No denominator was assumed nonzero without checking.
- [ ] No square root lost an absolute value or sign.
- [ ] No step divided by a possibly zero factor while solving an equation.
- [ ] All angle addition and sign formulas use the correct signs.
- [ ] All introduced formulas have checked derivations or explicitly declared foundational status; an index entry alone is insufficient.
- [ ] The proof is not circular (the desired identity was not assumed).
- [ ] If the claim is false, a **permissible** counterexample is supplied.
- [ ] The conclusion states the common domain, not an unjustified larger set.

## 19. How to extend this database

When adding an identity, create a new entry with these fields:

```text
ID: [unique stable ID]
Claim: [exact symbolic identity]
Domain: [original common domain, including all restrictions]
Method: [reciprocal | Pythagorean | addition | multiple-angle | conjugate | factor | product-to-sum | other]
Dependencies: [IDs of previously justified formulas]
Proof: [finite, logically ordered equalities]
Edge cases: [holes, sign cases, zero factors, non-equivalent transformations]
Countercheck: [at least two allowed test angles, when useful]
```

**Extension policy:** Prefer adding genuinely new proof structures rather than endlessly repeating equivalent cosmetic variations. Maintain the six-function core. Optional analytic proof tools are described separately in the v0.5 extension and require an explicit foundation profile and checker support. Hyperbolic functions remain outside this package.
