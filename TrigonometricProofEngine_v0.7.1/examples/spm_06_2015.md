# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$2 \cos{\left(x - \frac{\pi}{4} \right)} \cos{\left(x + \frac{\pi}{4} \right)} = \cos{\left(2 x \right)}$$

## Domain

No additional restrictions.

## Algebraic proof

Start with the LHS:

$$2 \cos{\left(x - \frac{\pi}{4} \right)} \cos{\left(x + \frac{\pi}{4} \right)}$$

1. **Use the compound-angle identity**

$$= 2 \left(\frac{\sqrt{2} \sin{\left(x \right)}}{2} + \frac{\sqrt{2} \cos{\left(x \right)}}{2}\right) \cos{\left(x + \frac{\pi}{4} \right)}$$

cos(A+B) = cos(A)*cos(B) - sin(A)*sin(B), with A = x, B = -pi/4. Use the exact standard-angle values.

2. **Use the compound-angle identity**

$$= 2 \left(\frac{- \sqrt{2} \sin{\left(x \right)}}{2} + \frac{\sqrt{2} \cos{\left(x \right)}}{2}\right) \left(\frac{\sqrt{2} \sin{\left(x \right)}}{2} + \frac{\sqrt{2} \cos{\left(x \right)}}{2}\right)$$

cos(A+B) = cos(A)*cos(B) - sin(A)*sin(B), with A = x, B = pi/4. Use the exact standard-angle values.

3. **Simplify the algebra**

$$= - \sin^{2}{\left(x \right)} + \cos^{2}{\left(x \right)}$$

Combine like terms and cancel common factors on the original domain.

4. **Use the double-angle identity**

$$= \cos{\left(2 x \right)}$$

cos(2*x) = -sin(x)**2 + cos(x)**2.

This is the RHS, so the identity is proved on its original common domain.
