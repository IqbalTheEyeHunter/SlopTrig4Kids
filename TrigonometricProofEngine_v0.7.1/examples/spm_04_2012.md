# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$\frac{2}{\cos{\left(2 x \right)} + 1} = \sec^{2}{\left(x \right)}$$

## Domain

- `2*cos(x)**2 ≠ 0`
- `cos(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$\frac{2}{\cos{\left(2 x \right)} + 1}$$

1. **Use the double-angle identity**

$$= \frac{2}{\left(2 \cos^{2}{\left(x \right)} - 1\right) + 1}$$

cos(2*x) = 2*cos(x)**2 - 1.

2. **Simplify the denominator**

$$= \frac{2}{2 \cos^{2}{\left(x \right)}}$$

Collect like terms in the denominator.

3. **Simplify the algebra**

$$= \left(\frac{1}{\cos{\left(x \right)}}\right)^{2}$$

Combine like terms and cancel common factors on the original domain.

4. **Use the quotient or reciprocal identity**

$$= \sec^{2}{\left(x \right)}$$

sec(x) = 1/cos(x)

This is the RHS, so the identity is proved on its original common domain.
