# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$\frac{\sin{\left(2 x \right)}}{2 \cos^{2}{\left(x \right)} + \tan^{2}{\left(x \right)} - \sec^{2}{\left(x \right)}} = \tan{\left(2 x \right)}$$

## Domain

- `cos(2*x) ≠ 0`
- `cos(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$\frac{\sin{\left(2 x \right)}}{2 \cos^{2}{\left(x \right)} + \tan^{2}{\left(x \right)} - \sec^{2}{\left(x \right)}}$$

1. **Use the Pythagorean identity**

$$= \frac{\sin{\left(2 x \right)}}{2 \cos^{2}{\left(x \right)} - 1}$$

sec(x)**2 - tan(x)**2 = 1.

2. **Use the double-angle identity**

$$= \frac{\sin{\left(2 x \right)}}{\cos{\left(2 x \right)}}$$

cos(2*x) = 2*cos(x)**2 - 1.

3. **Use the quotient or reciprocal identity**

$$= \tan{\left(2 x \right)}$$

tan(2*x) = sin(2*x)/cos(2*x)

This is the RHS, so the identity is proved on its original common domain.
