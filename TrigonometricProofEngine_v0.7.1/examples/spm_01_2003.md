# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$\tan{\left(x \right)} + \cot{\left(x \right)} = 2 \csc{\left(2 x \right)}$$

## Domain

- `cos(x) ≠ 0`
- `sin(2*x) ≠ 0`
- `sin(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$\tan{\left(x \right)} + \cot{\left(x \right)}$$

1. **Use the quotient or reciprocal identity**

$$= \frac{\sin{\left(x \right)}}{\cos{\left(x \right)}} + \cot{\left(x \right)}$$

tan(x) = sin(x)/cos(x)

2. **Use the quotient or reciprocal identity**

$$= \frac{\sin{\left(x \right)}}{\cos{\left(x \right)}} + \frac{\cos{\left(x \right)}}{\sin{\left(x \right)}}$$

cot(x) = cos(x)/sin(x)

3. **Combine the fractions**

$$= \frac{\sin^{2}{\left(x \right)} + \cos^{2}{\left(x \right)}}{\sin{\left(x \right)} \cos{\left(x \right)}}$$

Write the terms over a common denominator.

4. **Use the Pythagorean identity**

$$= \frac{1}{\sin{\left(x \right)} \cos{\left(x \right)}}$$

cos(u)**2 = 1 - sin(u)**2. Substitute for the squared terms, expand and collect like terms.

5. **Simplify the algebra**

$$= \frac{2}{2 \sin{\left(x \right)} \cos{\left(x \right)}}$$

Combine like terms and cancel common factors on the original domain.

6. **Use the double-angle identity**

$$= \frac{2}{\sin{\left(2 x \right)}}$$

sin(2*u) = 2*sin(u)*cos(u), with u = x.

7. **Use the quotient or reciprocal identity**

$$= 2 \csc{\left(2 x \right)}$$

csc(2*x) = 1/sin(2*x)

This is the RHS, so the identity is proved on its original common domain.
