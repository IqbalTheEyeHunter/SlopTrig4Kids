# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$- 2 \sin^{2}{\left(x \right)} - \cot^{2}{\left(x \right)} + \csc^{2}{\left(x \right)} = \cos{\left(2 x \right)}$$

## Domain

- `sin(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$- 2 \sin^{2}{\left(x \right)} - \cot^{2}{\left(x \right)} + \csc^{2}{\left(x \right)}$$

1. **Use the Pythagorean identity**

$$= 1 - 2 \sin^{2}{\left(x \right)}$$

csc(x)**2 - cot(x)**2 = 1.

2. **Use the double-angle identity**

$$= \cos{\left(2 x \right)}$$

cos(2*x) = 1 - 2*sin(x)**2.

This is the RHS, so the identity is proved on its original common domain.
