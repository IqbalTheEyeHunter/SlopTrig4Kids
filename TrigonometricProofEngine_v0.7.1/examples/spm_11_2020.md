# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$\frac{2 \sin{\left(x \right)} + \cos{\left(2 x \right)} - 1}{- \frac{\sin{\left(2 x \right)}}{2} + \cos{\left(x \right)}} = 2 \tan{\left(x \right)}$$

## Domain

- `(1 - sin(x))*cos(x) ≠ 0`
- `cos(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$\frac{2 \sin{\left(x \right)} + \cos{\left(2 x \right)} - 1}{- \frac{\sin{\left(2 x \right)}}{2} + \cos{\left(x \right)}}$$

1. **Use the double-angle identity**

$$= \frac{\left(\left(1 - 2 \sin^{2}{\left(x \right)}\right) + 2 \sin{\left(x \right)}\right) - 1}{\frac{\left(-1\right) \sin{\left(2 x \right)}}{2} + \cos{\left(x \right)}}$$

cos(2*x) = 1 - 2*sin(x)**2.

2. **Simplify the arithmetic**

$$= \frac{- 2 \sin^{2}{\left(x \right)} + 2 \sin{\left(x \right)}}{\frac{\left(-1\right) \sin{\left(2 x \right)}}{2} + \cos{\left(x \right)}}$$

Combine constants and remove common numerical factors.

3. **Use the double-angle identity**

$$= \frac{- 2 \sin^{2}{\left(x \right)} + 2 \sin{\left(x \right)}}{- \sin{\left(x \right)} \cos{\left(x \right)} + \cos{\left(x \right)}}$$

sin(2*u) = 2*sin(u)*cos(u), with u = x.

4. **Factor the numerator and denominator**

$$= \frac{2 \left(\sin{\left(x \right)} - 1\right) \sin{\left(x \right)}}{\left(\sin{\left(x \right)} - 1\right) \cos{\left(x \right)}}$$

Expose the common factor before cancelling it.

5. **Cancel the common factor**

$$= 2 \frac{\sin{\left(x \right)}}{\cos{\left(x \right)}}$$

Cancel the common factor. The original denominator must still be nonzero.

6. **Use the quotient or reciprocal identity**

$$= 2 \tan{\left(x \right)}$$

tan(x) = sin(x)/cos(x)

This is the RHS, so the identity is proved on its original common domain.
