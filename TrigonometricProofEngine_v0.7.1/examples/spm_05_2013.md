# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$\sin{\left(2 x \right)} \tan{\left(x \right)} = 1 - \cos{\left(2 x \right)}$$

## Domain

- `cos(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$\sin{\left(2 x \right)} \tan{\left(x \right)}$$

1. **Use the quotient or reciprocal identity**

$$= \frac{\sin{\left(x \right)}}{\cos{\left(x \right)}} \sin{\left(2 x \right)}$$

tan(x) = sin(x)/cos(x)

2. **Simplify the arithmetic**

$$= \frac{\sin{\left(x \right)} \sin{\left(2 x \right)}}{\cos{\left(x \right)}}$$

Combine constants and remove common numerical factors.

3. **Use the double-angle identity**

$$= \frac{2 \sin{\left(x \right)} \cos{\left(x \right)} \sin{\left(x \right)}}{\cos{\left(x \right)}}$$

sin(2*u) = 2*sin(u)*cos(u), with u = x.

4. **Simplify the algebra**

$$= 1 - \left(1 - 2 \sin^{2}{\left(x \right)}\right)$$

Combine like terms and cancel common factors on the original domain.

5. **Use the double-angle identity**

$$= 1 - \cos{\left(2 x \right)}$$

cos(2*x) = 1 - 2*sin(x)**2.

This is the RHS, so the identity is proved on its original common domain.
