# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$2 \cos^{2}{\left(x \right)} \tan{\left(x \right)} = \sin{\left(2 x \right)}$$

## Domain

- `cos(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$2 \cos^{2}{\left(x \right)} \tan{\left(x \right)}$$

1. **Use the quotient or reciprocal identity**

$$= 2 \frac{\sin{\left(x \right)}}{\cos{\left(x \right)}} \cos^{2}{\left(x \right)}$$

tan(x) = sin(x)/cos(x)

2. **Simplify the algebra**

$$= 2 \sin{\left(x \right)} \cos{\left(x \right)}$$

Combine like terms and cancel common factors on the original domain.

3. **Use the double-angle identity**

$$= \sin{\left(2 x \right)}$$

sin(2*u) = 2*sin(u)*cos(u), with u = x.

This is the RHS, so the identity is proved on its original common domain.
