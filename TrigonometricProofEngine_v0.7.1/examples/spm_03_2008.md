# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$\frac{2 \tan{\left(x \right)}}{2 - \sec^{2}{\left(x \right)}} = \tan{\left(2 x \right)}$$

## Domain

- `2 - sec(x)**2 ≠ 0`
- `cos(2*x) ≠ 0`
- `cos(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$\frac{2 \tan{\left(x \right)}}{2 - \sec^{2}{\left(x \right)}}$$

1. **Use the quotient or reciprocal identity**

$$= \frac{2 \frac{\sin{\left(x \right)}}{\cos{\left(x \right)}}}{2 - \sec^{2}{\left(x \right)}}$$

tan(x) = sin(x)/cos(x)

2. **Simplify the arithmetic**

$$= \frac{2 \sin{\left(x \right)}}{\left(2 - \sec^{2}{\left(x \right)}\right) \cos{\left(x \right)}}$$

Combine constants and remove common numerical factors.

3. **Use the quotient or reciprocal identity**

$$= \frac{2 \sin{\left(x \right)}}{\left(2 - \left(\frac{1}{\cos{\left(x \right)}}\right)^{2}\right) \cos{\left(x \right)}}$$

sec(x) = 1/cos(x)

4. **Simplify the algebra**

$$= \frac{2 \sin{\left(x \right)} \cos{\left(x \right)}}{2 \cos^{2}{\left(x \right)} - 1}$$

Combine like terms and cancel common factors on the original domain.

5. **Use the double-angle identity**

$$= \frac{\sin{\left(2 x \right)}}{2 \cos^{2}{\left(x \right)} - 1}$$

sin(2*u) = 2*sin(u)*cos(u), with u = x.

6. **Use the double-angle identity**

$$= \frac{\sin{\left(2 x \right)}}{\cos{\left(2 x \right)}}$$

cos(2*x) = 2*cos(x)**2 - 1.

7. **Use the quotient or reciprocal identity**

$$= \tan{\left(2 x \right)}$$

tan(2*x) = sin(2*x)/cos(2*x)

This is the RHS, so the identity is proved on its original common domain.
