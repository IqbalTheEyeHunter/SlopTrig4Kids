# Trigonometric Proof Report — v0.7.1

**Status: PROVED**

$$2 \sin^{2}{\left(x \right)} \cot^{2}{\left(x \right)} = \cos{\left(2 x \right)} + 1$$

## Domain

- `sin(x) ≠ 0`

## Algebraic proof

Start with the LHS:

$$2 \sin^{2}{\left(x \right)} \cot^{2}{\left(x \right)}$$

1. **Use the quotient or reciprocal identity**

$$= 2 \left(\frac{\cos{\left(x \right)}}{\sin{\left(x \right)}}\right)^{2} \sin^{2}{\left(x \right)}$$

cot(x) = cos(x)/sin(x)

2. **Simplify the algebra**

$$= \left(2 \cos^{2}{\left(x \right)} - 1\right) + 1$$

Combine like terms and cancel common factors on the original domain.

3. **Use the double-angle identity**

$$= \cos{\left(2 x \right)} + 1$$

cos(2*x) = 2*cos(x)**2 - 1.

This is the RHS, so the identity is proved on its original common domain.
